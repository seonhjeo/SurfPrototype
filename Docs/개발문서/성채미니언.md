# 성채 미니언 개발단위

대응 기획: [성채 미니언](../기획서/성채미니언.md).

## 진영별 생성과 일반·엘리트 능력치

- 기획: [생성](../기획서/성채미니언.md#생성--2026-09-30-확정), [능력치](../기획서/성채미니언.md#능력치--2026-09-30-확정).
- 독립 ON/OFF 설정은 기본 OFF다. 켜면 5초부터20초 간격으로 진영·라인당 일반1~10마리(기본3)를 생성하며 매5번째에 엘리트1마리를 추가한다. 엘리트 개수/주기와 스탯은 고정한다.
- 일반은 HP 10.5·공격력 4.5, 엘리트는 HP 300·공격력 18로 성 도로 동급 중립 강화 전 값의 HP·ATK만 1.5배를 사용한다.
- 나머지 이동속도·주기·감지·사거리는 동급 성 도로 중립과 같으며 맵 효과·웨이브 성장·고유 스킬은 없다.
- 라인 0 조합은 진영당 가상 1경로 분량이다. 종료 시 생성 중단, 재대전 시 초기화를 연결한다.
- 검증: 5·25·85초 생성, 일반 수량1/10·라인0~3의 진영/전체 수, 일반 유지와 엘리트1 추가, 고정 능력치, 기능 OFF·입력 보존과 재대전을 확인한다.

## 미니언 전투·날씨·SP 연결

- 기획: [모드와 진영](../기획서/성채미니언.md#모드와-진영), [능력치](../기획서/성채미니언.md#능력치--2026-09-30-확정).
- 진영·일반/엘리트 분류를 유지하고 상대 유닛·미니언·포탑과 중립을 공격한다. 유닛은 같은 이동 라인, 독립 포탑은 물리 거리를 사용하며 아군과 다른 이동 라인 유닛은 제외한다.
- 플레이어 유닛과 같은 비 ×0.8·안개 ×0.7, 제어 효과와 둔화 중첩 정책을 적용한다.
- 최소 아군 수 집계에는 포함하고 사냥꾼 중립 보너스·기사단장 버프에서는 제외한다.
- 미니언 처치 보상과 미니언이 중립을 처치한 보상의 소유진영 귀속은 [SP 개발단위](SP.md)의 설정으로 처리한다.
- 검증: 양 진영 공격/아군 제외, 라인 제한, 4개 맵·3개 날씨, 미니언 중립 처치·사망 보상과 버프·사냥꾼 분류를 확인한다.
- [x] 개발 완료
