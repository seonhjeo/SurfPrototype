# 화면 구성 개발단위

대응 기획: [프로토타입 화면 구성](../기획서/화면구성.md). 확인이 필요한 세부 규칙은 해당 구현 전에 확정한다.

## 로비 모드와 대전 방식 선택

- 기획: [로비](../기획서/화면구성.md#로비).
- 기본·자동획득 금지·처치획득 금지 모드 선택을 제공하고 세 모드에서 비공개 방 생성·참가·AI 대전으로 연결한다. 모드별 SP 규칙은 [모드 설정](게임모드.md)을 따른다(2026-09-30 확정).
- 모드 선택을 2열·두 줄로 배치한다. 기본 모드는 첫 줄의 2열 전체를 차지하고, 자동획득 금지 모드·처치획득 금지 모드는 다음 줄에서 같은 폭의 1열씩 사용한다.
- 처치획득 금지 모드 안내에 시작 20 SP·초당 1 SP 회복·처치 SP 보상 없음을 표시한다.
- AI와 방 생성은 로비 선택 모드를 전달하고, 코드 참가는 방장이 정한 모드를 전달받는다.
- 검증: 기본 모드의 첫 줄 전체 폭과 다음 줄 두 모드의 같은 폭·높이, 세 모드의 표시명·선택·규칙 안내와 세 진입 경로에서 현재 경기 모드·대전 방식이 유지되는지 확인한다.

## 비공개 방과 초대 코드

- 기획: [로비](../기획서/화면구성.md#로비), [대기방](../기획서/화면구성.md#대기방).
- 1대1 비공개 방 생성 시 숫자 6자리 초대 코드를 발급하고 대기방에서 확인할 수 있게 한다.
- 로비에서 코드를 입력하면 방장이 정한 모드의 대기방에 참가하고 서버가 해당 모드를 전달하게 한다.
- 로그인 없이 두 기기가 참가하며 코드는 방이 열려 있는 동안 유효하다. 잘못된 코드·만료·없는 방·가득 찬 방은 오류를 안내한다.
- 대기방 참가자 이탈은 타이머·양쪽 준비 초기화, 방장 이탈은 방 종료다. 경기 중 이탈·연결 종료는 패배이며 재접속은 없다(2026-09-30 확정).
- 검증: 코드의 숫자 구성과 6자리 길이, 세 모드의 초대로 두 플레이어가 같은 방·모드에 연결되는지, 잘못된 코드·정원 초과 등 확정된 실패 처리를 확인한다.
- [x] 개발 완료

## 대기방 정보와 준비 상태

- 기획: [대기방](../기획서/화면구성.md#대기방), [덱 빌딩](../기획서/덱빌딩.md).
- 경기 모드와 시작 SP·회복량·처치 보상, 맵·날씨, 유닛 선택 슬롯, 남은 30초, 준비 버튼과 상대 준비 여부를 표시한다.
- 맵 정보와 함께 [맵별 기믹](../기획서/맵과중립몬스터.md#맵별-기믹--2026-09-30-확정)을 공개한다. 일반 몬스터 수의 적용 지점과 늪의 보스 포함 속도 효과를 알 수 있게 한다.
- 상대 덱은 비공개로 유지하며 서버도 자신의 덱과 상대의 입장·준비 상태만 전달한다.
- 양측 준비 완료 또는 제한시간 종료 시 기존 선택을 유지하며 빈 슬롯만 중복 없이 랜덤으로 채워 5슬롯 덱을 게임에 전달한다. 자동 채움과 준비 규칙은 [덱 빌딩 개발단위](덱빌딩.md)와 연결한다.
- 두 참가자가 모두 입장한 뒤 공통 30초를 시작하며 혼자 기다릴 때는 카운트다운하지 않는다.
- 최소 1슬롯 선택 시 준비를 허용하고 준비 중 덱 편집을 잠근다. 상대가 미준비일 때만 준비 취소를 허용하며, 취소 후 편집을 풀고 남은 시간은 유지한다.
- 검증: 세 모드의 이름·SP 규칙과 처치획득 금지 모드의 처치 보상 없음 표시, 맵 4종의 기믹 설명, 혼자 대기·두 번째 참가자 입장, 0슬롯과 1슬롯 준비 조건, 상대 준비 표시, 편집 잠금·취소 조건, 조기 시작·시간 종료의 자동 채움과 단일 화면 전환을 확인한다.
- [x] 개발 완료

## AI 대전과 게임 화면 연결

- 기획: [전체 흐름](../기획서/화면구성.md#전체-흐름), [게임](../기획서/화면구성.md#게임).
- AI 대전도 로비 → 대기방 → 게임 순서로 진행하고 현재 경기의 모드·환경·덱을 유지한다.
- 게임 화면의 모드·SP 시작값·회복·처치 보상 표시를 현재 경기 규칙과 일치시킨다. 자동획득 금지 모드는 자연 회복 없음, 처치획득 금지 모드는 처치 보상 없음을 표시한다.
- 게임 화면에서도 현재 맵의 기믹을 표시하고 대기방의 설명 및 실제 전투 효과와 일치하게 한다.
- AI가 참가하면 두 참가자가 모인 것으로 처리하고 AI는 덱 선택을 마치는 즉시 자동 준비한다. 실제 전투는 기존 [전투 개발단위](전투진행.md)와 연결한다.
- 검증: 세 모드의 AI 1대1과 게임 SP·회복·처치 보상 표시, 게임 화면의 맵별 기믹, AI 덱 선택 완료 후 자동 준비·상대 준비 표시, 두 대전 방식의 설정 유지와 게임 시작, 대기 시간이 5분 플레이 시간을 소모하지 않는지 확인한다.
- [x] 개발 완료

## 경기 결과와 재대전

- 기획: [결과와 재대전](../기획서/화면구성.md), [경기 이탈](../기획서/전투진행.md).
- 승리·패배·무승부와 종료 사유를 표시하고 다시 준비·로비 복귀를 제공한다.
- PVP는 양 참가자의 재대전 선택 뒤 대기방에서 다시 덱 선택·준비를 진행한다. AI도 대기방을 거치고 양 대전 방식 모두 이전 경기 모드를 유지한다.
- 검증: 양쪽 관점의 결과, 이탈 패배, 로비 복귀, 세 모드의 재대전 유지와 SP 재설정, 처치획득 금지 모드의 시작 20·초당 1·처치 보상 없음 유지, 이전 경기 상태가 남지 않는 재대전을 확인한다.
