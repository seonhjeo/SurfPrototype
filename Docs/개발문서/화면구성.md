# 화면 구성 개발단위

대응 기획: [프로토타입 화면 구성](../기획서/화면구성.md).

## 로비 대전 방식 선택

- 기획: [로비](../기획서/화면구성.md#로비).
- 기존 모드 선택 영역을 삭제하고 AI 대전·비공개 방 만들기·6자리 코드 참가를 제공한다.
- AI/방 만들기는 설정 팝업을 먼저 열고 완료 시 준비방으로 연결한다. 코드 참가는 팝업 없이 서버가 고정한 방장 설정의 준비방으로 연결한다.
- 초대 코드 참가 안내를 방장 경기 설정 공유에 맞춰 갱신한다.
- 검증: 로비 프리셋 선택 제거, 두 생성 버튼의 팝업 진입, 직접 참가와 잘못된 코드 오류를 확인한다.
- [x] 개발 완료

## 경기 설정 팝업

- 기획: [경기 설정 팝업](../기획서/화면구성.md#경기-설정-팝업--2026-10-01-확정), [설정 항목](../기획서/게임모드.md#설정-항목과-수량-범위).
- SP와 전장 기능의 ON/OFF·수량/보상 입력을 공통 match-settings에 연결한다. 투석기·기름은 ON/OFF만 제공하고 전투 스탯 입력은 노출하지 않는다.
- 일반 항목의 OFF 입력 비활성화·값 보존, 맵 기본 중립 수와 소환/중립의 기본 처치 보상 선택, 범위·단위·오류 안내를 구현한다. 이동 라인은 OFF와 0을 동기화하되 숫자 입력을 유지하고 같은 팝업에서 직전 양수 수량을 복원한다. 이동 라인 0~3과 포탑 배치 라인 1~3·라인당 수량 1~3을 독립 입력한다.
- 취소·기본 초기화·설정 완료를 제공하고 최근 완료 설정을 현재 앱 세션에서 유지한다. 취소한 변경은 완료 설정에 반영하지 않는다.
- 설정 완료 전에는 AI 준비 타이머나 비공개 방 생성을 시작하지 않는다. 완료 후 선택한 경로만 실행하며 취소는 로비에 머문다.
- 모바일 스크롤과 키보드 입력·팝업 포커스·닫기·완료/취소 버튼 접근을 확인한다.
- 검증: 모든 항목/양끝값, ON/OFF 복원·취소·초기화·재열기·세션 기억, 완료 전 타이머/방 없음과 완료 후 단일 진입을 확인한다.
- [x] 개발 완료

## 비공개 방과 초대 코드

- 기획: [로비](../기획서/화면구성.md#로비), [대기방](../기획서/화면구성.md#대기방), [방 수명](../기획서/화면구성.md#방-수명과-오류-처리--2026-09-30-확정).
- 설정 완료 후 1대1 방을 만들고 숫자 6자리 초대 코드를 발급한다. 제한된 경기 설정을 서버에서 검증·변환해 room.rules로 고정하고 참가자에게 공유한다.
- 임의 raw rules overrides는 적용하지 않는다. 코드 참가자는 팝업 없이 방장 설정을 수신한다.
- 로그인·코드 유효 수명·잘못된 코드/만료/정원 오류·준비방 이탈·경기 이탈 패배·재접속 없음 규칙을 유지한다.
- 검증: 사용자 지정 수량/SP를 사용하는 생성·참가·양쪽 공통 규칙, 무효 설정 거부와 6자리 코드·기존 실패 처리를 확인한다.
- [x] 개발 완료

## 대기방 정보와 준비 상태

- 기획: [대기방](../기획서/화면구성.md#대기방), [덱 빌딩](../기획서/덱빌딩.md).
- 확정된 시작 SP·회복·종류별 보상·기능 ON/OFF·수량을 확인할 수 있는 UI와 맵·날씨·덱·시간·준비 상태를 제공한다.
- state.rules/room.rules를 사용해 방장의 설정과 실제 맵 기믹을 표시한다. 중립 OFF와 직접 수량 재정의도 설명에 반영한다.
- 상대 덱을 비공개로 유지하고 서버는 자신의 덱과 상대 입장·준비 상태만 전달한다.
- 둘 다 입장 후 공통 30초, 1슬롯 이상 준비·준비 중 잠금·상대 미준비 시 취소, 양측 준비/시간 종료 시 빈 슬롯만 중복 없이 랜덤 채움 규칙을 유지한다.
- 검증: AI/방장/참가자의 설정 확인·맵 기본/직접 수량/중립OFF, 상대 덱 비공개, 혼자 대기·입장·준비·자동 채움과 한 번의 전투 전환을 확인한다.
- [x] 개발 완료

## AI 대전과 게임 화면 연결

- 기획: [전체 흐름](../기획서/화면구성.md#전체-흐름), [게임](../기획서/화면구성.md#게임).
- 로비 → 설정 팝업 → AI 준비방 → 게임 흐름에 최종 규칙을 연결한다. 설정 완료 후에만 준비 시간을 시작하며 AI 덱 선택 후 자동 준비한다.
- 게임 SP·회복·종류별 처치 보상과 실제 맵 기믹 표시를 state.rules에 맞춘다.
- 지정 라인·미니언·여러 포탑/상자를 표시하고 기본 기능 OFF 전장도 유지한다. HP·피해·주기 등 기존 스탯은 그대로 사용한다.
- 검증: 기본/사용자 조합의 AI 경기 시작부터 종료, SP 및 실제 생성 수량, 소환 입력·모바일 크기와 준비 시간이 경기 시간을 소모하지 않는지 확인한다.
- [x] 개발 완료

## 경기 결과와 재대전

- 기획: [결과와 재대전](../기획서/화면구성.md#결과와-재대전--2026-09-30-확정), [경기 이탈](../기획서/전투진행.md).
- 결과·종료 사유·다시 준비·로비 복귀를 제공한다. AI는 이전 설정으로, PVP는 양쪽 재대전 선택 뒤 같은 방 코드/설정으로 준비방을 시작한다.
- 재대전에서는 팝업을 다시 열지 않는다. room.rules 유지와 덱·준비·전투·초기 SP·미니언/중립·포탑/상자·생성 타이머 초기화를 확인한다.
- 검증: 양쪽 결과·이탈·로비 복귀, AI/PVP 수량/SP 유지 및 이전 경기 개체/타이머가 남지 않는 재대전을 확인한다.
- [x] 개발 완료
