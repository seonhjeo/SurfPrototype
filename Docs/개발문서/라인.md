# 라인 개발단위

대응 기획: [라인](../기획서/라인.md).

## 경로와 모드별 라인 설정

- 기획: [모드별 적용](../기획서/라인.md#모드별-적용--2026-10-01-확정), [라인 0 조합](../기획서/라인.md#라인-0과-별도-기능의-조합-초기안).
- 팝업의 이동 라인 ON/OFF·0~3 입력을 공통 규칙으로 연결한다. 기본 OFF·0은 자유 이동이며 다시 ON은 보존된 수량을 사용한다.
- 1~3라인은 양 성채 앞에서 합류하는 연속 경로로 구성하고 진영별 표시 변환과 경로 진행 좌표를 관리한다.
- 경유점 `(6,17.6)/(6,16.4)/(X,14)/(X,6)/(6,3.6)/(6,2.4)`와 1라인 X=6·2라인 X=3/9·3라인 X=2.2/6/9.8의 초기안을 적용한다.
- 이동 라인 0의 미니언은 가상 1경로 분량이다. 포탑은 독립적인 배치 라인 1~3과 라인당 1~3개를 양 진영 대칭으로 생성하며 자유 이동을 제한하지 않는다.
- 검증: 0~3라인 유효값, 양 성채 합류, 양 진영 대칭, 라인 0 기존 동작과 기능 조합을 확인한다.

## 소환·중립 진입과 최소 아군 수 배정

- 기획: [라인 진입과 배정](../기획서/라인.md#라인-진입과-배정).
- 중립 일반·보스와 드래그 소환은 최근접 경로에 최단 거리로 진입한다. 진입 전 새 공격·스킬을 막되 이미 발생한 투사체/제어 효과에 대한 피격 면역은 부여하지 않는다.
- 단순 터치는 성채 앞에서 생성하고 살아 있는 플레이어 소환 유닛·일반 및 엘리트 미니언 수가 가장 적은 라인에 배정한다.
- 합류 구간에도 라인 소속을 유지한다. 동일 거리·동일 집계는 낮은 lane ID를 선택한다.
- 검증: 양 진영 탭·드래그, 최근접 진입, 미니언을 포함한 집계, 죽은 개체 제외, 동률 재현성과 합류 구간의 소속을 확인한다.

## 라인 이동과 모든 전투 효과 제한

- 기획: [이동·전투·스킬 제한](../기획서/라인.md#이동전투스킬-제한).
- 추적·전진·돌진·은신·넉백을 배정 경로에 제한하고 다른 라인으로 이탈하지 않게 한다.
- 단일·광역·지속 피해·CC·버프의 유닛 대상 필터에 같은 이동 라인 조건을 적용한다. 성채는 공통 종착 목표, 상자는 공용 구조물이다. 포탑은 배치 라인 ID를 이동 라인 ID와 분리하고 물리 사거리로 공격·피격을 연결한다.
- 사냥꾼은 성채 미니언에 중립 보너스를 주지 않는다. 기사단장은 같은 라인의 플레이어 소환 유닛만 강화한다.
- 검증: 가까운 다른 라인의 기본 공격·폭발·화상·얼음·돌진 피해 및 버프 제외, 경로 넉백·은신·돌진, 대상 해제 후 재탐색과 성채 공격을 확인한다.
