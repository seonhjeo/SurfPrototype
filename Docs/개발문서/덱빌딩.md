# 덱 빌딩 개발단위

대응 기획: [덱 빌딩](../기획서/덱빌딩.md). 기획서의 `확인 필요` 항목은 해당 구현 전에 확정한다.

## 매칭 후 환경 공개와 덱 선택

- 기획: [진입과 환경 공개](../기획서/덱빌딩.md#진입과-환경-공개).
- 매칭 완료 후 선택된 맵·날씨를 표시하고 사용할 유닛을 선택할 수 있게 한다.
- 슬롯 수, 유닛 후보, 중복 제한, 상대 선택 공개 여부는 사용자 답변 후 적용한다.
- 검증: 공개한 환경과 실제 경기 환경이 일치하고 확정된 선택 제한이 적용되는지 확인한다.
- [ ] 개발 완료

## 30초 선택 제한과 자동 채움

- 기획: [선택 제한시간](../기획서/덱빌딩.md#선택-제한시간).
- 선택 제한시간을 30초로 설정하고, 만료 시 미선택 슬롯에만 랜덤 유닛을 배정한다.
- 랜덤 후보와 중복 제한은 확정된 덱 규칙을 반영한다.
- 검증: 전부 미선택·일부 선택·전부 선택 상태에서 만료를 확인하고 기존 선택이 유지되는지 확인한다.
- [ ] 개발 완료

## 덱 확정과 플레이 진입

- 기획: [선택 제한시간 및 확인 필요](../기획서/덱빌딩.md#선택-제한시간).
- 덱 확정 결과를 플레이 단계에 전달한다.
- 조기 완료, 완료 버튼, 선택 변경 가능 시점은 사용자 답변 후 적용한다.
- 검증: 플레이 단계에서 확정된 덱을 사용하며 단계 전환이 중복 발생하지 않는지 확인한다.
