# 덱 빌딩 개발단위

대응 기획: [덱 빌딩](../기획서/덱빌딩.md). 기획서의 `확인 필요` 항목은 해당 구현 전에 확정한다.

## 대기방 환경 공개와 덱 선택

- 기획: [진입과 환경 공개](../기획서/덱빌딩.md#진입과-환경-공개), [덱 구성](../기획서/덱빌딩.md#덱-구성).
- AI/비공개 방의 설정 완료 또는 코드 참가 후 실제 맵/날씨를 공개하고 덱을 선택한다. 환경 선택 정책도 확인할 수 있으며 재대전은 고정 유지·무작위 재추첨 뒤 공개한다.
- 덱은 5슬롯으로 구성하며 고정 제공 유닛 중에서 중복 없이 선택한다.
- 고정 목록은 [플레이어 유닛 10종](../기획서/플레이어유닛.md)을 사용하고 상대 덱 선택은 비공개로 유지한다(2026-09-30 확정).
- 검증: 공개한 환경과 실제 경기 환경이 일치하고 확정된 선택 제한이 적용되는지 확인한다.

## 30초 선택 제한과 자동 채움

- 기획: [선택 제한시간](../기획서/덱빌딩.md#선택-제한시간).
- 양쪽 참가자 입장 후 공통 선택 제한시간 30초를 시작한다. 시간 만료 또는 양측 준비에 따른 조기 시작 시 미선택 슬롯에만 랜덤 유닛을 배정한다.
- 이미 선택된 유닛을 제외한 고정 제공 목록에서 중복 없이 채운다.
- 대기방 참가자 이탈 시 타이머·준비를 초기화하고 새 참가자가 들어오면 30초를 다시 시작한다.
- 검증: 혼자 대기 시 타이머 미진행, 두 번째 참가자 입장 후 30초 시작, 시간 만료·조기 시작 모두 기존 선택을 유지하며 중복 없는 5슬롯을 만드는지 확인한다. 전부 미선택의 시간 만료도 포함한다.
- [x] 개발 완료

## 덱 확정과 플레이 진입

- 기획: [선택 제한시간](../기획서/덱빌딩.md#선택-제한시간), [준비와 조기 시작](../기획서/덱빌딩.md#준비와-조기-시작).
- 덱 확정 결과를 플레이 단계에 전달한다.
- 준비 버튼과 상대 준비 상태를 표시하고, 양쪽 모두 준비하거나 제한시간이 종료되면 게임 화면으로 이동한다.
- 최소 1슬롯 선택 시 준비를 허용하고 준비 중 덱 변경을 막는다. 상대 미준비일 때만 준비 취소·덱 편집 재개를 허용하며, 남은 시간은 초기화하지 않는다.
- AI는 덱 선택을 마치면 자동으로 준비한다. 대기방 표시는 [화면 구성 개발단위](화면구성.md)와 연결한다.
- 양측 준비로 조기 시작할 때도 시간 만료와 같은 자동 채움 규칙을 적용해 5슬롯을 확정한다.
- 검증: 최소 슬롯 조건, 준비 중 편집 차단, 상대 준비에 따른 취소 가능 여부, AI 자동 준비, 양측 1슬롯 선택 후 준비 시 자동 채움, 조기 시작·시간 만료의 중복 전환 방지를 확인한다.
- [x] 개발 완료
