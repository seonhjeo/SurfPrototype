# 덱 빌딩 개발단위

대응 기획: [덱 빌딩](../기획서/덱빌딩.md). 기획서의 `확인 필요` 항목은 해당 구현 전에 확정한다.

## 매칭 후 환경 공개와 덱 선택

- 기획: [진입과 환경 공개](../기획서/덱빌딩.md#진입과-환경-공개), [덱 구성](../기획서/덱빌딩.md#덱-구성).
- 매칭 완료 후 선택된 맵·날씨를 표시하고 사용할 유닛을 선택할 수 있게 한다.
- 덱은 5슬롯으로 구성하며 고정 제공 유닛 중에서 중복 없이 선택한다.
- 고정 목록은 [플레이어 유닛 10종](../기획서/플레이어유닛.md)을 사용하고, 상대 선택 공개 여부는 사용자 답변 후 적용한다.
- 검증: 공개한 환경과 실제 경기 환경이 일치하고 확정된 선택 제한이 적용되는지 확인한다.
- [ ] 개발 완료

## 30초 선택 제한과 자동 채움

- 기획: [선택 제한시간](../기획서/덱빌딩.md#선택-제한시간).
- 선택 제한시간을 30초로 설정하고, 만료 시 미선택 슬롯에만 랜덤 유닛을 배정한다.
- 이미 선택된 유닛을 제외한 고정 제공 목록에서 중복 없이 채운다.
- 검증: 전부 미선택·일부 선택·전부 선택 상태에서 만료 시 기존 선택이 유지되고 5슬롯에 중복이 없는지 확인한다.
- [ ] 개발 완료

## 덱 확정과 플레이 진입

- 기획: [선택 제한시간](../기획서/덱빌딩.md#선택-제한시간), [레디와 조기 시작](../기획서/덱빌딩.md#레디와-조기-시작).
- 덱 확정 결과를 플레이 단계에 전달한다.
- 레디 버튼을 제공하고 양쪽 모두 레디를 누르면 남은 선택 시간에 관계없이 즉시 플레이를 시작한다.
- 레디를 누를 수 있는 조건, 레디 후 선택 변경·취소 가능 여부는 사용자 답변 후 적용한다.
- 검증: 양쪽 레디 시 조기 시작, 한쪽만 레디 시 대기, 시간 만료 전환, 확정 덱 전달 및 중복 전환 방지를 확인한다.
