# 성채 공격과 구조물 개발단위

대응 기획: [성채 공격과 구조물](../기획서/구조물.md).

## 성채 자동 범위 공격

- 기획: [성채의 투석기·끓는 기름](../기획서/구조물.md#성채의-투석기끓는-기름--2026-09-30-확정).
- 성채 공격 기본 OFF로 기존 동작을 보존한다. 켜면 원거리 투석기와 근거리 끓는 기름을 각각 자동 사용한다.
- 각 공격의 설정값으로 타이밍·범위·피해를 계산하고 아군·다른 라인을 제외한다. 처치 보상은 소유진영과 SP 설정에 연결한다.
- 투석기는 피해18·사거리7·대상중심반경1.25·주기3초, 기름은 피해8·사거리2.4·성채중심반경2.4·주기1.5초다. 최근접 대상을 선택하고 동일 거리는 낮은 entity ID를 우선한다.
- 기존 성채 HP·피해·제어 처리와 승패 판정은 유지한다.
- 성채 무기·포탑의 대상과 피해 범위는 소환 유닛·미니언·중립만 포함한다. 상대 성채·포탑·상자는 직접/범위 피해 모두 제외한다.
- 검증: OFF 기존 무공격, 양 진영의 두 공격, 거리·범위 경계, 같은 라인·아군 제외, 소유진영 보상과 파괴 후 공격 중단을 확인한다.

## 체력이 있는 진영별 1차 포탑

- 기획: [1차 포탑](../기획서/구조물.md#1차-포탑--2026-09-30-확정).
- 기본 OFF다. 켜면 진영당 라인당 1개를 자기 진영 중앙에 배치하고 라인 0은 가상 1경로 분량을 사용한다.
- HP250·피해12·사거리4·주기1.5초·판정반경0.45 U·자기 진영 경로진행률24%의 초기안을 설정으로 관리한다. 포탑 생존 중에도 성채에 피해를 줄 수 있다.
- 단일 최근접 적 유닛·미니언·중립만 공격하고 성채·상자는 공격하지 않는다. 동일 거리는 낮은 entity ID, 화상·얼음 피해 허용/CC 무시를 적용한다. 포탑 파괴 보상은 없다.
- 물리 이동은 봉쇄하지 않으며 살아 있는 포탑과 겹친 소환만 취소한다. 파괴 뒤 소환과 통과를 막지 않는다.
- 검증: 0~3라인 개수·위치, 양 진영 전투, 포탑 파괴·보상, 성채 선행 공격, 겹침 소환 취소/SP 미소비와 파괴 후 소환을 확인한다.
- [x] 개발 완료

## SP 상자 피해 보상과 수명

- 기획: [SP 상자](../기획서/구조물.md#sp-상자--2026-09-30-확정).
- 기본 OFF다. 켜면 중앙에 HP가 있는 상자를 배치하고 플레이어 소환 유닛만 공격 대상으로 선택한다.
- 단일·광역·지속 피해의 실제 HP 감소량에 비율을 곱해 공격자 소유 플레이어에게 SP를 지급한다. 과잉 피해·중복 타격·사후 피해를 보상에서 제외한다.
- 중앙 (6,10)의 공용 1개 상자는 lane null로 모든 라인에서 공격 가능하며 다른 라인 유닛 피해를 허용하지 않는다. 최종 SP 최대치와 처치 보상 ON/OFF의 독립 설정을 적용한다.
- 초기 HP200·몸체반경0.5·상호작용반경3.2 U·HP당0.1 SP·respawnDelay null을 사용한다. 유닛 사거리+3.2 U로 접근하며 몸체반경은 소환/광역 판정에 사용한다.
- 소환 유닛의 화상·얼음구역 피해도 허용하고 CC는 무시한다. 상자 겹침 소환은 취소하지만 이동을 봉쇄하지 않는다.
- 근접 직사각형/부채꼴은 상호작용 반경3.2를 판정 여유로 사용하고 투사체 폭발·얼음·돌진 범위는 실제 몸체반경0.5로 판정한다.
- 영구 소멸과 지연 재생성 정책을 둘 다 지원한다. 종료 시 재생성 중단, 재대전 시 상자·타이머·체력을 초기화한다.
- 검증: 플레이어 소환 유닛만 공격, 피해 10/잔여 HP 3의 보상 기준 3, SP 상한, 피해원 소유진영, 화상·폭발, 다른 라인 제외, 영구 소멸·시간 재생성과 경기 종료를 확인한다.
