# SP 개발단위

대응 기획: [SP 자원](../기획서/SP.md). 기획서의 `확인 필요` 항목은 해당 구현 전에 확정한다.

## SP 보유량과 기본 회복

- 기획: [용도와 보유량](../기획서/SP.md#용도와-보유량), [획득 방식](../기획서/SP.md#획득-방식).
- 플레이어별 SP를 관리하고 세 모드 공통으로 최대 50을 적용한다.
- [게임 모드 개발단위](게임모드.md)의 공통 데이터에 따라 기본 모드는 시작 5·초당 1 SP, 자동획득 금지 모드는 시작 20·초당 0 SP, 처치획득 금지 모드는 시작 20·초당 1 SP를 두 진영에 적용한다.
- 시작·최대 SP 및 시간당 지급 enabled/amount를 최종 `ModeRules.sp`에서 읽고 미래 코드 조합에서 독립 조절한다. 모든 획득에 해당 설정의 상한을 적용한다.
- 검증: 세 모드의 시작값 5/20/20, 시간 경과에 따른 회복량 1/0/1, 최대치 도달 및 초과 회복·처치 보상을 확인한다.
- [x] 개발 완료

## 소환 비용 소비

- 기획: [용도와 보유량](../기획서/SP.md#용도와-보유량), [소환과 동시 처치](../기획서/SP.md).
- 플레이어 유닛 소환 시 SP를 사용한다.
- [유닛 목록](../기획서/플레이어유닛.md)의 비용을 적용한다. SP 부족은 소환 불가로 표시하고 실제 소환 성공 시에만 차감한다. 취소·실패는 차감하지 않는다(2026-09-30 확정).
- 검증: 비용과 같은 SP·부족한 SP·연속 소환·취소 또는 실패 시 합의한 처리가 이루어지는지 확인한다.
- [x] 개발 완료

## 처치 보상

- 기획: [획득 방식](../기획서/SP.md#획득-방식), [처치 보상 귀속](../기획서/SP.md#처치-보상-귀속).
- 기본·자동획득 금지 모드에서 중립 몬스터 및 적 유닛 처치 시 종류별 SP 보상을 지급하고 보유량이 50을 넘지 않게 한다.
- 처치획득 금지 모드는 공통 모드 데이터의 `killSpRewards: false`에 따라 일반 중립 몬스터·중립 보스·적 유닛의 처치 보상을 지급하지 않는다. 중립 몬스터가 플레이어 소환 유닛을 죽여 상대에게 지급하는 보상도 0이다.
- 플레이어 소환 유닛 사망 시 마지막 타격 주체와 관계없이 소유자의 상대 플레이어에게 지급한다. 중립 몬스터가 처치한 경우도 포함한다.
- 중립 몬스터·중립 보스는 자신의 소환 유닛이 마지막 타격을 가한 플레이어에게만 지급한다.
- 보상은 유닛 목록의 처치 SP, 일반 중립 몬스터 1 SP·보스 8 SP 초기안을 적용한다. 웨이브 강화로 보상을 늘리지 않는다.
- 기존 지급 정책을 유지하면서 `summoned/minion/elite/neutral`별 enabled·amount·multiplier를 읽는다. amount null은 개체 정의의 reward × multiplier다.
- 신규 일반·엘리트 미니언은 각각 1·3 SP의 초기안이며 사망 시 소유자의 상대에게 지급한다. 성채·포탑·미니언이 중립을 마지막 타격으로 죽이면 공격자의 소유진영에 지급한다.
- 중립 동시 마지막 타격은 전투 계산에서 먼저 처리되어 대상을 처치한 타격으로 귀속하고 중복 지급하지 않는다(2026-09-30 확정).
- 검증: 처치획득 금지 모드의 일반 중립·보스·적 유닛·중립에 의한 유닛 사망 보상이 0인지 확인한다. 기존 두 모드의 중립 몬스터에 의해 사망한 적 유닛 보상, 중립·보스 마지막 타격 귀속, 종류별 보상, 중복 지급 방지와 최대치 처리도 확인한다.
- [x] 개발 완료

## SP 상자 실제 피해 보상

- 기획: [종류별 지급 설정](../기획서/SP.md#종류별-지급-설정과-신규-보상-초기안), [SP 상자](../기획서/구조물.md#sp-상자--2026-09-30-확정).
- 상자에 실제 감소한 HP × spPerDamage만큼 소환 유닛 소유자에게 지급한다. 초기안은 HP당 0.1 SP이며 과잉 피해·죽은 상자에 가한 피해는 0이다.
- 소수 정밀도를 유지하고 최종 SP 상한을 적용한다. 처치 및 시간 보상 enabled와 상자 설정은 독립적이다.
- 검증: 단일·광역·화상 등 피해원의 귀속, 실제 HP 감소량, 최대치와 소수 SP, 다른 공격원 제외와 처치 보상 OFF 조합을 확인한다.
- [x] 개발 완료
