# SP 개발단위

대응 기획: [SP 자원](../기획서/SP.md). 기획서의 `확인 필요` 항목은 해당 구현 전에 확정한다.

## SP 보유량과 기본 회복

- 기획: [용도와 보유량](../기획서/SP.md#용도와-보유량), [획득 방식](../기획서/SP.md#획득-방식).
- SP 자동 획득 한도 50을 고정하고 팝업의 시작ON/OFF·1~50 정수와 회복ON/OFF·0.1~50/초(0.1단위)를 두 진영에 동일 적용한다.
- 기본 시작5·회복1/초를 유지하며 시작OFF는 실제0, 회복OFF는 지급0이다. OFF 입력량은 경기 설정 모델에 보존한다.
- 호환성을 위해 ModeRules.sp.maximum을 유지하되 시간 회복 한도로 사용한다. 보유 SP가 한도 미만이면 min(한도, 현재 SP + 초당량 × 경과시간)으로 회복하고 한도 이상이면 값을 보존한다. 정지 시간의 회복량은 누적하지 않는다.
- 초기 SP는 sp.initial 그대로 설정해 내부 초기값이 한도보다 높아도 보존한다. 실제 팝업의 시작 SP 범위는 1~50을 유지한다. PVP 상태 전달도 초과 보유량을 보존하며 재대전은 시작값으로 초기화한다.
- 검증: 기본값·입력양끝·시작/회복OFF,0.1단위 소수 계산, 두 진영 동일값, 49.9→50의 회복 경계·50/초과에서 정지와 값 보존·내부 초기 초과값·재대전 초기화를 확인한다.
- [x] 개발 완료

## 소환 비용 소비

- 기획: [용도와 보유량](../기획서/SP.md#용도와-보유량), [소환과 동시 처치](../기획서/SP.md).
- 플레이어 유닛 소환 시 SP를 사용한다.
- [유닛 목록](../기획서/플레이어유닛.md)의 비용을 적용한다. SP 부족은 소환 불가로 표시하고 실제 소환 성공 시에만 차감한다. 취소·실패는 차감하지 않는다(2026-09-30 확정).
- 한도를 넘긴 보유 SP에서도 실제 보유량으로 비용을 판정·차감한다. 소비 후 한도 이상이면 회복을 멈춘 채 유지하고 한도 미만이면 다음 계산부터 회복을 재개한다.
- 검증: 비용과 같은 SP·부족한 SP·초과 보유 SP의 연속 소환, 한도 미만 소비 후 회복 재개·취소 또는 실패 시 합의한 처리를 확인한다.
- [x] 개발 완료

## 처치 보상

- 기획: [획득 방식](../기획서/SP.md#획득-방식), [처치 보상 귀속](../기획서/SP.md#처치-보상-귀속).
- 네 종류의 보상은 각각 ON/OFF로 조절한다. 소환/중립은 기본(null) 또는 고정 1~50 정수, 일반/엘리트 미니언은 직접 1~50 정수를 입력한다. amount null은 기존 reward×1이며 고정 amount는 카테고리 공통값이다.
- 기본은 소환 유닛별 보상, 일반/엘리트1/3 SP, 중립 일반/보스1/8 SP다. 중립 고정량은 일반/보스에 같은 수를 적용하며 웨이브 성장은 보상을 바꾸지 않는다.
- 소환/성채미니언 사망은 마지막 타격과 무관하게 소유자의 상대에게 지급한다. 중립은 마지막 타격을 가한 성채·포탑·소환유닛·미니언 소유진영에 지급한다.
- 카테고리OFF는 모든 사망 원인/공격원에서 지급0이다. 동시에 들어온 중립 마지막 타격은 먼저 처치한 계산에 한 번만 귀속한다.
- 보상은 현재 보유 SP에 전액 가산한다. 자동 획득 한도 도달 전후와 관계없이 소수 정밀도를 유지하고 50 초과분을 보존한다.
- 검증: 네 종류의OFF·기본·고정1/50, 중립에 의한 소환 유닛 사망·구조물/미니언 마지막 타격·중복 방지, 한도 전후의 보상 전액 지급·초과 보존을 확인한다.
- [x] 개발 완료

## 포탑 파괴 소유진영 보상

- 기획: [포탑 파괴 보상](../기획서/SP.md#포탑-파괴-보상--2026-10-01-확정), [1차 포탑](../기획서/구조물.md#1차-포탑--2026-09-30-확정).
- MatchSettings.towerLossReward의 enabled/amount를 ModeRules.sp.towerLoss로 연결한다. 기본 OFF·입력 5, ON의 허용량은 1~50 정수다.
- 포탑 HP가 양수에서 0 이하가 될 때 파괴된 포탑의 소유진영에 1회 지급한다. 공격자 유형·진영·중립 여부는 보상 귀속을 바꾸지 않는다.
- 이미 파괴된 포탑의 재피해·지속 피해에서 중복 지급을 막는다. 자동 획득 한도 50과 관계없이 보상을 전액 가산하며 다른 처치/상자 보상의 독립 설정을 적용한다.
- 검증: 양 진영·상대 소환/미니언/중립 파괴·단일/지속 피해, OFF와 고정 1/50, 한도 전후 전액 지급·중복 방지·재대전 새 포탑을 확인한다.
- [x] 개발 완료

## SP 상자 실제 피해 보상

- 기획: [종류별 지급 설정](../기획서/SP.md#종류별-지급-설정과-신규-보상-초기안), [SP 상자](../기획서/구조물.md#sp-상자--2026-09-30-확정).
- 상자에 실제 감소한 HP × spPerDamage만큼 소환 유닛 소유자에게 지급한다. 초기안은 HP당 0.1 SP이며 과잉 피해·죽은 상자에 가한 피해는 0이다.
- 소수 정밀도를 유지하고 자동 획득 한도와 관계없이 전액 가산한다. 처치 및 시간 보상 enabled와 상자 설정은 독립적이다.
- 검증: 단일·광역·화상 등 피해원의 귀속, 실제 HP 감소량, 한도 전후의 전액·소수 SP 지급과 초과 보존, 다른 공격원 제외와 처치 보상 OFF 조합을 확인한다.
- [x] 개발 완료
