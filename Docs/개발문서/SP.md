# SP 개발단위

대응 기획: [SP 자원](../기획서/SP.md). 기획서의 `확인 필요` 항목은 해당 구현 전에 확정한다.

## SP 보유량과 기본 회복

- 기획: [용도와 보유량](../기획서/SP.md#용도와-보유량), [획득 방식](../기획서/SP.md#획득-방식).
- 플레이어별 SP를 관리하고 최대 50, 기본 초당 1 SP 회복을 적용한다.
- 시작 SP는 사용자 답변 후 적용한다.
- 검증: 합의한 시작값, 시간 경과에 따른 회복량, 최대치 도달 및 초과 회복을 확인한다.
- [ ] 개발 완료

## 소환 비용 소비

- 기획: [용도와 보유량 및 확인 필요](../기획서/SP.md#용도와-보유량).
- 플레이어 유닛 소환 시 SP를 사용한다.
- 유닛별 비용, SP 부족 처리, 차감 시점, 소환 취소·실패 처리는 사용자 답변 후 적용한다.
- 검증: 비용과 같은 SP·부족한 SP·연속 소환·취소 또는 실패 시 합의한 처리가 이루어지는지 확인한다.
- [ ] 개발 완료

## 처치 보상

- 기획: [획득 방식](../기획서/SP.md#획득-방식).
- 중립 몬스터 및 적 유닛 처치 시 종류별 SP 보상을 지급하고 보유량이 50을 넘지 않게 한다.
- 보상 수치와 귀속 기준, 중립 몬스터·성채에 의한 처치 및 동시 처치 처리는 사용자 답변 후 적용한다.
- 검증: 종류별 보상과 귀속, 한 처치의 중복 지급 방지, 최대치 부근의 보상 처리를 확인한다.
