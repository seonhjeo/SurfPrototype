# 개발문서 인덱스

개발단위별 구현 내용을 플레이어, 맵 등 파트별 문서로 관리한다.
각 개발단위의 작업 상태는 해당 단위 설명 끝의 완료 체크 항목으로 표시한다.

기획서의 확정 사항을 개발단위로 나누어 등록한다. 미완료·구현 중인 단위는 검증이 끝날 때까지 미체크로 유지한다.
각 문서에서 연결한 기획서의 `확인 필요` 항목은 사용자 답변을 받은 뒤 해당 구현에 적용한다.
기획서의 초기 밸런스안은 구현·대전 검증 후 조정하며, 문서 작성이나 산술 검증만으로 개발 완료 처리하지 않는다.

2026-09-30 사용자 답변에 따라 화면·비공개 PVP·연속 전장·탐색·성채·소환·이탈 규칙을 동기화했다. 경기 결과·재대전 단위를 추가했으며 문서 확정만으로 완료 처리하지 않았다.

맵별 일반 수·늪의 일반/보스 속도 +30%·성 도로 표시명, 양 진영 플레이어 유닛의 보스 표시 규격, 대기방·게임의 기믹 설명과 대응 계산을 동기화했다. 영향을 받은 7개 개발단위는 구현·검증 후 완료로 갱신했다.

자동획득 금지 모드 요청에 따라 [모드 데이터와 경기 설정 유지](게임모드.md)를 추가하고 게임개요·화면구성·SP·밸런스기준의 영향을 받은 9개 개발단위를 구현·검증 후 완료로 갱신했다.

처치획득 금지 모드 요청을 모드·게임개요·화면구성·SP·맵·유닛·밸런스기준에 동기화했다. 시작 20 SP·초당 1 SP·모든 처치 보상 없음 규칙이 영향을 주는 12개 개발단위를 구현·검증 후 완료로 갱신했다. 이때 전체 39개 개발단위 중 38개가 완료 상태였다.

후속 표시명 변경과 로비 두 줄 배치를 기획·개발문서에 동기화했다. 명칭을 수정한 11개 개발단위의 완료 체크를 갱신하고, 기본 모드의 첫 줄 전체 폭·다음 줄 두 금지 모드의 나란한 배치와 AI 대기방의 새 표시명을 브라우저에서 확인했다. 전투 규칙과 내부 식별자는 유지한다.

공개 사이트에서도 비공개 PVP를 운영하기 위한 [Render 서버 배포와 Vercel 화면 연결](공개PVP배포.md) 2개 단위를 완료했다. 기존 WebSocket과 단일 Node.js 서버 구조를 유지하며 최초 기동 대기·PVP 좌표 보간을 반영했다. Node.js 24의 전체 자동 테스트 59개·타입 검사·프로덕션 빌드를 통과했고, `main`의 `5df7f3a`를 Render Live·Vercel Production Ready 상태로 배포했다. 세 모드의 공개 WebSocket 방·전투·소환·이탈, 공개 브라우저 두 탭의 결과·재대전을 확인했다. 서로 다른 기기·네트워크 검증은 미확인이다. 이 배포 시점에는 전체 41개 개발단위 중 40개가 완료 상태였다.

[AI 상대 대전과 후반 압박 검증](밸런스기준.md#ai-상대-대전과-후반-압박-검증)은 실제 사용자 플레이로 경기 길이·반복 전략·조작감을 확인해야 하므로 미완료로 유지한다. [밸런스 검증 기록](밸런스기준.md)에 기믹 변경 전후 기록, 자동획득 금지 모드 추가 후 43개 자동 테스트, 처치획득 금지 모드 추가 후 48개 자동 테스트·브라우저 검증을 구분했다. 사용자 로컬 테스트와 `dev` 병합은 별도 절차다.

후속 모드 설정 리팩터링으로 [라인](라인.md)·[성채 미니언](성채미니언.md)·[성채 공격과 구조물](구조물.md)과 독립 기능/보상 설정·조합 검증 단위를 추가했다. 당시 세 모드는 새 기능 기본 OFF·라인 0을 유지했다. 메인 에이전트가 자동 테스트95개·타입검사 포함 프로덕션 빌드, 기존36환경의 이전 dev 대비 매초 상태 동일, AI 소환·신규3라인 시각·390×844 모바일 크기에서 클릭·드래그·결과/재대전·콘솔 오류0을 확인해 영향을 받은 구현 단위를 완료로 갱신했다. 2026-09-30 사용자가 로컬 테스트 완료를 알리고 `dev` 병합 및 배포를 명시적으로 요청했다. [PR #8](https://github.com/seonhjeo/SurfPrototype/pull/8) 병합 후 `main`의 `9291655`를 Vercel Production Ready·Render Live로 확인했고 세 모드의 공개 WebSocket 및 Production 브라우저 두 탭 검증을 통과했다. 상세 증거는 [최신 공개 배포 검증](공개PVP배포.md#모드-설정-리팩터링-production-검증--2026-09-30)에 기록했다. 실제 사용자 밸런스 검증 단위는 미완료로 유지한다. 이 배포 시점에는 전체52개 개발단위 중51개가 완료 상태였다.

2026-10-01 두 고정 추가 모드를 경기 설정 팝업으로 대체한다. 사용자 확정 범위에 따라 ON/OFF·수량/SP량, 서버 제한 입력 검증, 설정 완료 후 준비방/방 생성, 직접 코드 참가, 세션 기억·취소·초기화와 재대전 유지 규칙을 동기화했다. 이동 라인 0~3과 독립 포탑 배치 라인 1~3·라인당 포탑 1~3을 반영했다. 새 팝업 단위를 추가하고 변경된 단위는 검증 전 미체크로 되돌린 뒤 통합 검증을 근거로 완료 처리했다. 과거 공개 배포·프리셋 검증은 당시 증거로 유지하며 이번 사용자 로컬 테스트/병합을 대신하지 않는다.

2026-10-01 메인 에이전트가 자동 테스트 104개·타입 검사·프로덕션 빌드, 팝업 취소/범위 거부/포커스, 이동 0라인과 독립 포탑·상자의 AI 자연 종료/재대전, 375×667 화면과 두 탭 PVP를 확인했다. 영향받은 34개 단위를 완료로 갱신해 전체 53개 중 52개 완료다. 실제 모바일 기기 터치·서로 다른 기기/네트워크·이번 변경의 공개 배포는 미확인이다. [상세 검증 기록](게임모드.md#경기-설정-팝업-구현-검증--2026-10-01)을 참조하며 사용자 로컬 테스트와 병합은 별도다.

2026-10-01 후속 환경 선택·포탑 파괴 SP 요청을 같은 작업 브랜치에 추가한다. 맵/날씨 정책 스냅샷과 실제 경기 환경을 구분하고 재대전의 고정 유지/무작위 재추첨을 구현한다. 포탑 소유진영 지급의 별도 SP 단위를 추가하고 영향받은 단위를 새 검증 전 미체크로 되돌린 뒤 최종 검증에 따라 완료 처리했다. 이전 104개 검증과 이번 후속 검증을 구분한다.

후속 통합 검증은 자동 테스트 117개·타입 검사 포함 빌드, 고정 늪/안개의 AI 자연 종료·재대전, 고정 숲/비의 PVP 설정 공유, 375×667 환경·SP 입력/초기화/취소/51 거부를 통과했다. 영향받은 16개 단위를 완료해 전체 54개 중 53개 완료이며 실제 사용자 밸런스 검증은 미완료다. [상세 검증](게임모드.md#환경-선택과-포탑-파괴-보상-검증--2026-10-01)을 참조한다. 실제 모바일 터치·외부 기기/네트워크·공개 배포·사용자 로컬 테스트는 확인 범위에 포함하지 않는다.

2026-10-01 사용자 PR 검토 후 배포 요청으로 [PR #9](https://github.com/seonhjeo/SurfPrototype/pull/9)를 병합했다. `main`·`ab8c4ae`의 CI 성공과 같은 SHA의 Vercel Production completed/SUCCESS·Render Live, 공개 화면/health HTTP 200을 확인했다. 공개 WebSocket의 기본/혼합/고정 설정 공유·덱 비공개·실제 포탑 소유진영 SP 지급과 Production 두 탭에서 숲·비 고정/포탑 소유진영 보상 공유·양쪽 소환·성채 자연 파괴·재대전 환경/규칙 유지와 새 경기 초기화·참가자 이탈 승리·콘솔 오류/경고 0을 확인했다. [배포 증거와 확인 범위](공개PVP배포.md#경기-설정-팝업-production-검증--2026-10-01)를 기록하며 실제 사용자 밸런스 단위는 미완료로 유지한다. 앞선 구현 기록의 공개 배포 미확인은 각 검증 당시의 범위다.

2026-10-01 후속 요청으로 [SP](SP.md)의 sp.maximum 값 50을 시간 회복 한도로 변경하고, 처치·포탑 파괴·상자 보상은 한도 전후에 전액 가산한다. 50 이상에서 초과량 보존·자동 획득 정지, 소비 후 50 미만에서 재개, 내부 초기 초과 SP와 PVP 상태 전달·실제 보유량 표시를 반영한다. 시작 입력 1~50·개별 보상 입력 범위와 재대전 초기화는 유지한다. SP·게임모드·구조물·밸런스·화면의 변경된 14개 개발단위는 미체크로 되돌린 뒤 자동 테스트 125개·타입 검사 포함 빌드와 실제 AI 대전·375×667 HUD/드래그·비공개 방의 상자 보상 `62 / 50 SP` 표시 검증에 따라 완료 처리했다. 전체 54개 중 53개 완료이며 실제 사용자 밸런스 단위는 미완료다. [상세 검증](SP.md#sp-초과-보유-구현-검증--2026-10-01)의 실제 장치 터치·외부 기기/네트워크·사용자 로컬 테스트·공개 배포 미확인은 구현 당시의 범위다. 과거 검증의 상한 기록은 당시 동작의 증거다.

같은 날 사용자 명시 병합·배포 요청에 따라 [PR #10](https://github.com/seonhjeo/SurfPrototype/pull/10)을 병합했다. `main`·`7b61b6f`의 GitHub CI SUCCESS와 동일 SHA의 Vercel Production SUCCESS·Render 배포 성공/Live 로그, 공개 화면·서버 상태 HTTP 200을 확인했다. 공개 WebSocket의 실제 상자 파괴 보상 후 회복 ON은 69 SP 보존·30 SP 소비 후 39→40 회복 재개, 회복 OFF는 67 SP 보존·소비 후 37 유지와 양 클라이언트 상태 일치·덱 비공개·참가자 이탈 후 방장 승리를 확인했다. 공개 브라우저는 새 SP 도움말·콘솔 오류/경고 0을 확인했으며 이번 공개 브라우저 경기는 실행하지 않았다. [배포 ID·시각과 상세 범위](공개PVP배포.md#sp-초과-보유-production-검증--2026-10-01)를 기록하며 사용자 테스트 수행 보고·실제 장치 터치·외부 기기/네트워크·장기 밸런스 확인은 별도로 남긴다.
