# 날씨 개발단위

대응 기획: [날씨](../기획서/날씨.md). 확정된 세 날씨와 선택 확률 초기안을 적용한다.

## 날씨 선택과 경기 환경

- 기획: [적용 규칙](../기획서/날씨.md#적용-규칙), [선택 확률 초기안](../기획서/날씨.md#선택-확률-초기안).
- 화창함·비·안개만 제공하고 바람은 후보에 포함하지 않는다.
- 맵 4종은 각각 25%, 날씨 3종은 각각 1/3로 독립 선택하는 초기안을 적용한다.
- 비공개 방·AI 대전의 대기방에서 양쪽에 같은 환경을 공개하고 경기 종료까지 날씨를 유지한다.
- 검증: 12개 맵·날씨 조합, 덱 선택 화면과 경기의 일치, 경기 중 날씨 유지, 사람·AI의 동일한 환경을 확인한다.

## 플레이어 유닛 보정과 중립 제외

- 기획: [종류와 효과](../기획서/날씨.md#종류와-효과).
- 비는 플레이어 유닛 이동속도 × 0.8, 안개는 감지 거리 × 0.7을 적용한다. 화창함은 수치를 바꾸지 않는다.
- 일반 중립 몬스터와 중립 보스에는 날씨 보정을 적용하지 않으며, 경기 중 새로 소환된 양쪽 플레이어 유닛에도 동일하게 적용한다.
- 안개는 감지 각도와 공격 사거리를 바꾸지 않는다. 원거리 감지 4.9 U와 공격 사거리 5 U를 별도로 판정한다.
- 스킬 이동 배율과 날씨는 곱한다. 도적의 은신 가속뿐 아니라 기사의 기준 돌진 속도에도 날씨·이동 둔화 배율을 적용한다.
- 검증: 양쪽 유닛·일반 중립·보스 구분, 3→2.1 및 7→4.9 감지, 날씨·도적 가속·얼음 둔화 조합과 중복 보정 방지를 확인한다.
- [x] 개발 완료
