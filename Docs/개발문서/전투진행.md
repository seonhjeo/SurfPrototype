# 전투 진행 개발단위

대응 기획: [전투 진행과 승패](../기획서/전투진행.md). 기획서의 `확인 필요` 항목은 해당 구현 전에 확정한다.

## 플레이 제한시간

- 기획: [플레이 단계](../기획서/전투진행.md#플레이-단계).
- 대기방의 덱 빌딩을 마치고 게임 화면의 플레이를 시작한 뒤 제한시간 5분을 적용한다.
- 권장 플레이시간 3분은 밸런스 목표로 관리하며 자동 종료 규칙으로 사용하지 않는다.
- 검증: 덱 선택 시간이 플레이 시간을 소모하지 않고 5분 종료가 정확히 발생하는지 확인한다.

## 성채와 승패 판정

- 기획: [승리 조건](../기획서/전투진행.md#승리-조건), [무승부 조건](../기획서/전투진행.md#무승부-조건).
- 양쪽 성채의 남은 체력을 관리하고 제한시간 내 상대 성채 파괴 시 승리를 판정한다.
- 성채 초기·최대 체력은 양쪽 1,000의 초기안을 사용하고 중립 몬스터의 성채 공격·파괴도 반영한다.
- 제한시간 종료 시 남은 성채 체력을 비교하여 더 많은 플레이어의 승리를 판정한다.
- 시간 종료 시 체력 동률 또는 양쪽 성채 동시 파괴는 무승부로 판정한다.
- 성채는 방어력이 없고 기본 공격·스킬·화상 피해를 받으며 제어 효과는 무시한다. 현재 세 모드는 자체 공격 OFF이며 켠 조합은 [구조물 개발단위](구조물.md)의 두 자동 공격을 사용한다. 포탑 생존 여부와 관계없이 성채 피해를 적용한다. 시간 종료와 동시 발생 시 성채 파괴를 우선 판정한다(2026-09-30 확정).
- 검증: 양쪽 각각의 파괴 승리, 시간 종료 시 체력 우세·열세·동률, 동시 파괴 무승부를 확인한다.
- [x] 개발 완료

## 경기 종료와 이탈 처리

- 기획: [승리 조건](../기획서/전투진행.md#승리-조건), [성채 기능과 판정 순서](../기획서/전투진행.md).
- 확정된 결과 이후 추가 전투로 승패가 바뀌지 않도록 경기 종료를 처리한다.
- 경기 중 연결 종료·플레이어 이탈은 패배이며 재접속은 없다. 결과에서 다시 준비·로비 복귀를 제공한다(2026-09-30 확정).
- 종료 뒤 중립·미니언 생성과 구조물 공격·상자 재생성을 멈추고 재대전은 같은 설정으로 개체·SP·웨이브·타이머를 초기화한다.
- 검증: 종료 처리가 한 번만 이루어지고 두 플레이어의 결과가 일치하는지 확인한다.
- [x] 개발 완료
