# 전투 진행 개발단위

대응 기획: [전투 진행과 승패](../기획서/전투진행.md). 기획서의 `확인 필요` 항목은 해당 구현 전에 확정한다.

## 플레이 제한시간

- 기획: [플레이 단계](../기획서/전투진행.md#플레이-단계).
- 덱 빌딩 이후 플레이 제한시간 5분을 적용한다.
- 권장 플레이시간 3분은 밸런스 목표로 관리하며 자동 종료 규칙으로 사용하지 않는다.
- 검증: 덱 선택 시간이 플레이 시간을 소모하지 않고 5분 종료가 정확히 발생하는지 확인한다.
- [ ] 개발 완료

## 성채와 승패 판정

- 기획: [승리 조건](../기획서/전투진행.md#승리-조건).
- 양쪽 성채의 남은 체력을 관리하고 제한시간 내 상대 성채 파괴 시 승리를 판정한다.
- 제한시간 종료 시 남은 성채 체력을 비교하여 더 많은 플레이어의 승리를 판정한다.
- 동률, 동시 파괴, 종료와 파괴의 동시 발생, 성채 자체 전투 기능은 사용자 답변 후 적용한다.
- 검증: 양쪽 각각의 파괴 승리, 시간 종료 시 체력 우세·열세와 확정된 예외 조건을 확인한다.
- [ ] 개발 완료

## 경기 종료와 이탈 처리

- 기획: [승리 조건과 확인 필요](../기획서/전투진행.md#승리-조건).
- 확정된 결과 이후 추가 전투로 승패가 바뀌지 않도록 경기 종료를 처리한다.
- 연결 종료·플레이어 이탈 규칙은 사용자 답변 후 적용한다.
- 검증: 종료 처리가 한 번만 이루어지고 두 플레이어의 결과가 일치하는지 확인한다.
- [ ] 개발 완료
