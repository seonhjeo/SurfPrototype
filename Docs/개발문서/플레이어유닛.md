# 플레이어 유닛 개발단위

대응 기획: [플레이어 유닛 목록](../기획서/플레이어유닛.md). 사용자 지정값과 초기 밸런스안을 구분하고 공통 전투·스킬과 연결한다.

## 유닛 10종과 기본 능력치

- 기획: [기본 능력치](../기획서/플레이어유닛.md#기본-능력치), [추가 능력치 초기안](../기획서/플레이어유닛.md#추가-능력치-초기안).
- 전사·궁수·도적·방패병·마법사·기사·저주술사·사냥꾼·기사단장·대마도사를 고정 목록으로 제공한다.
- 소환SP·체력·공격력·감지/사거리는 사용자 지정값, 이동속도·주기·기본 처치SP는 기존 초기안을 사용한다. 소환 유닛 보상OFF면 종류/사망 원인과 무관하게0, ON은 기본 또는 공통 고정1~50을 적용한다.
- 사용자 밸런스 조정에 따라 사냥꾼의 초기·최대 체력을 80에서 60으로 낮춘다(2026-09-30 확정).
- 공통 거리 단위 U를 사용하고 사람·AI가 동일한 목록과 능력치로 덱을 구성·소환하게 한다.
- 소환 유닛 보상을 공통 summoned enabled/amount에 연결한다. amount null은 종류별reward×1이며 고정량은 종류별 보상을 대체하고 귀속 정책은 유지한다.
- 검증: 10종의 수치가 표와 일치하며 소환·날씨 적용·모드별 처치 보상에 연결되는지 확인한다. 사냥꾼 체력 조정 후 타입 검사·빌드와 자동 테스트 36개를 통과하고, 390×844 모바일 브라우저에서 카드 체력 60·터치 소환 초기/최대 체력 60/60을 확인했다.
- [x] 개발 완료

## 단일 대상 기본 공격

- 기획: [기본 공격](../기획서/플레이어유닛.md#기본-공격).
- 궁수·도적·방패병·기사·저주술사·사냥꾼의 단일 대상 공격을 구현한다.
- 궁수는 화살을 사용하고, 사냥꾼은 일반 중립 몬스터와 보스에 기본 피해 2배를 적용한다.
- 이동 라인 ON은 같은 라인의 유닛만 단일 대상으로 선택하며 포탑은 거리로 선택한다. 사냥꾼 미니언 피해는 5로 중립 배율을 주지 않고 상자·포탑의 피해 정책을 적용한다.
- 검증: 다른 대상에게 피해가 전파되지 않고, 사냥꾼의 플레이어 상대 피해 5·중립 상대 피해 10이 구분되는지 확인한다.
- [x] 개발 완료

## 광역 기본 공격과 경직

- 기획: [기본 공격](../기획서/플레이어유닛.md#기본-공격).
- 전사·기사단장은 전방 직사각형 세로베기, 마법사·대마도사는 투사체 충돌점의 원형 폭발을 적용한다.
- 대상마다 온전한 피해를 한 번 적용하고 아군에는 피해를 주지 않는다. 기사단장·대마도사는 0.15초 경직을 적용한다.
- 이동 라인 ON의 유닛 광역 피해·경직은 같은 라인에만 적용한다. 독립 포탑·상자는 물리 범위에 따른 피해만 받고 경직은 무시한다. 상자 피해는 실제 HP 감소 SP 보상에 연결한다.
- 검증: 범위 경계, 복수 대상 개별 피해, 아군 제외, 보스 경직 및 은신 도적의 광역 피해를 확인한다.
- [x] 개발 완료
