## 기본 규칙과 경기 설정 유지

- 기획: [기본 규칙과 설정 조합](../기획서/게임모드.md#기본-규칙과-설정-조합--2026-10-01-확정), [진입과 경기 설정 유지](../기획서/게임모드.md#진입과-경기-설정-유지).
- `limited-sp`·`no-kill-sp` 두 고정 프리셋을 삭제하고 `standard`의 기본 규칙을 유지한다. 로비에서 프리셋을 선택하는 흐름은 [화면 구성](화면구성.md)으로 대체한다.
- 기본값은 시작 5·자동 회복 1/초·SP 자동 획득 한도 50·처치 기본 보상이며 중립 ON, 라인·미니언·성채 무기·포탑·상자 OFF다. 시간 회복만 한도를 적용하고 비시간 보상은 전액 가산한다.
- AI 경기와 비공개 방은 맵/날씨·SP·기능 설정 완료 후 시작한다. 코드 참가자는 팝업 없이 방장의 전투 규칙·환경 선택 정책과 실제 환경을 공유한다.
- [로컬 설정 프리셋](로컬설정프리셋.md)은 두 생성 경로에서 공유하고 불러온 편집본을 설정 완료 시에만 확정한다. 최근 완료 설정은 세션에서만 기억하고 저장된 프리셋은 직접 선택한다. 취소는 경기 편집만 폐기하며 즉시 저장한 프리셋 관리는 유지한다.
- 서버가 생성 설정을 검증하고 최종 rules와 room.environmentSettings를 별도 고정한다. 임의 raw rules는 허용하지 않으며 참가·전투·재대전에서 같은 규칙/환경 정책을 유지한다.
- AI/PVP 재대전은 고정 맵/날씨를 유지하고 random 항목만 재추첨한다. 새 SP·개체·타이머를 사용하며 양 진영에 동일 실제 환경을 적용한다.
- 검증: 두 프리셋 제거, 기본 회귀, AI와 PVP의 설정 전달·두 진영 적용, 참가자 설정 공유, 초과 SP의 서버 상태 전달·회복 정지/재개, 재대전 유지 및 서버 임의 규칙 거부를 확인한다.
- [x] 개발 완료

## 기능과 수량 설정의 검증·변환

- 기획: [설정 항목과 수량 범위](../기획서/게임모드.md#설정-항목과-수량-범위), [설정 모델과 검증](../기획서/게임모드.md#설정-모델과-검증).
- `src/game/match-settings.ts`에서 팝업용 스키마·기본값·검증·ModeRules 변환과 실제 환경 선택을 공통 관리한다. 환경 map/weather 각각 random 또는 기존 식별자를 허용하고 잘못된 환경 키/값은 거부한다. 일반 항목은 OFF에도 입력값을 보존한다. 이동 라인은 OFF와 count 0을 동기화하며 직전 양수 라인 수는 같은 팝업 안에서만 복원한다.
- 시작 ON/OFF·1~50 정수와 회복 ON/OFF·0.1~50/초(0.1 단위)를 지원한다. 소환/중립 보상은 ON/OFF·기본 또는 고정 1~50 정수, 일반/엘리트 미니언 보상은 ON/OFF·1~50 정수다. SP 자동 획득 한도는 50이며 sp.maximum 필드를 유지한다. 개별 입력 범위와 최종 보유 SP의 초과 허용을 구분한다.
- 이동 라인 ON/OFF·0~3, 중립 ON/OFF·맵 기본 또는 지점·진영당 1~10, 미니언 ON/OFF·진영·이동 라인당 일반 1~10, 상자 ON/OFF·공용 1~3을 지원한다.
- 포탑은 ON/OFF·배치 라인 1~3·각 진영의 배치 라인당 1~3개를 지원한다. 배치 라인 수는 이동 라인 수와 독립적이며 이동 라인 0에서도 적용한다.
- 투석기·끓는 기름은 각각 ON/OFF만 노출한다. HP·피해·주기·강화 배율·엘리트 추가 주기/수량·중립 보스 수는 기존 전투 규칙을 사용한다.
- `neutralWaves.count` 기본 null은 맵별 수량이며 towers.count·towers.laneCount·spBox.count 기본은 1이다. 포탑 배치 ID와 유닛 이동 라인 ID를 분리하고 양 진영 대칭 배치를 사용한다. 상자는 y=10에서 x=6 / x=4·8 / x=2·6·10을 사용한다.
- 처치 amount null은 기본 reward×1이고 고정 amount는 카테고리 공통 보상이다. towerLossReward는 기본 OFF·입력 5와 ON의 1~50 정수를 sp.towerLoss로 연결한다. 제한된 설정 외 클라이언트 재정의는 적용하지 않는다.
- 검증: 유효 범위 양끝, 잘못된 타입·비유한 수·범위 초과·소수 개체 수·추가 속성 거부, OFF 값 보존 및 기본 조합 회귀를 확인한다.
- [x] 개발 완료

- 브라우저에서 기본 AI 소환, 신규3라인·미니언·포탑·상자 시각 표시, 390×844 모바일 크기에서 클릭·드래그, 결과·재대전과 콘솔 오류0을 확인했다.
