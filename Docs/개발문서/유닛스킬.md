# 유닛 스킬 개발단위

대응 기획: [유닛 스킬과 전투 효과](../기획서/유닛스킬.md). 미제공 수치와 효과 운용 초기안은 플레이 테스트로 조정한다.

## 스킬 준비와 대상 조건

- 기획: [스킬 수치 초기안](../기획서/유닛스킬.md#스킬-수치-초기안), [발동과 대상 처리 초기안](../기획서/유닛스킬.md#발동과-대상-처리-초기안).
- 최초 스킬은 소환 후 각 쿨타임이 지나야 준비하고, 재사용 쿨타임은 발동 시점부터 계산한다.
- 기사·기사단장은 적이 없어도 준비 즉시 사용하고, 도적을 포함한 나머지는 공격 가능한 대상이 기본 사거리 안에 들어올 때 사용한다.
- 스킬과 기본 공격 동시 준비 시 스킬을 먼저 사용하고 기본 공격은 자신의 공격 주기만큼 뒤로 미룬다.
- 성채에는 피해·화상을 적용하지만 넉백·기절·경직·둔화 등 제어 효과는 무시한다(2026-09-30 확정).
- 이동 라인 ON은 유닛 발동·효과에 같은 이동 라인 조건을 적용한다. 독립 포탑은 거리/물리 범위로 공격·피격하며 구조물은 피해·지속 피해 허용과 CC 무시를 따른다. 상자는 소환 유닛 피해만 허용한다.
- 검증: 첫 쿨타임, 무대상 대기와 예외 즉시 사용, 전진 중 대상 진입, 기본 공격 지연을 확인한다.
- [x] 개발 완료

## 전사·궁수·방패병·사냥꾼 공격 스킬

- 기획: [스킬 수치 초기안](../기획서/유닛스킬.md#스킬-수치-초기안).
- 전사는 강한 광역 세로베기, 궁수는 단일 고피해 화살과 넉백, 방패병은 전방 부채꼴 피해와 넉백을 적용한다.
- 사냥꾼은 단일 15 피해를 주되 일반 중립 몬스터·보스에 30 피해를 준다.
- 이동 라인 ON은 유닛의 세로베기·넉백·단일 피해를 같은 라인에 적용하며 넉백은 경로를 따른다. 포탑 피해는 물리 범위로 판정하고 미니언에는 사냥꾼 중립 배율을 주지 않는다.
- 검증: 피해·범위·쿨타임, 넉백 거리·방향·지형 제한, 보스 넉백, 사냥꾼의 보스 대상 배율을 확인한다.
- [x] 개발 완료

## 도적 은신과 기사 돌진

- 기획: [스킬 수치 초기안](../기획서/유닛스킬.md#스킬-수치-초기안), [발동과 대상 처리 초기안](../기획서/유닛스킬.md#발동과-대상-처리-초기안).
- 도적은 3초간 은신·이동속도 1.5배를 동시에 적용해 적을 무시하고 전진하고, 종료 후 정상 행동으로 복귀한다.
- 은신 시 추적 대상에서 해제하며 새 단일 대상으로 잡히지 않는다. 광역 피해를 받아도 남은 은신 시간은 유지하는 초기안을 적용한다.
- 기사는 적 성채 방향으로 최대 4 U를 6 U/초로 돌진하고 경로 내 각 대상에 25 피해를 한 번 적용한다.
- 이동 라인 ON은 은신 전진·돌진을 경로상 진행 거리로 계산한다. 돌진 유닛 피해는 같은 라인만 주며 독립 포탑은 실제 몸체 범위로 피격한다. 포탑·상자는 이동을 봉쇄하지 않는다.
- 검증: 도적의 은신·가속 동시 종료와 광역 피해, 기사 무대상 돌진, 다중 충돌 중복 피해 방지, 성채·지형·제어 효과에 따른 돌진 종료를 확인한다.
- [x] 개발 완료

## 마법사 화상과 대마도사 얼음구역

- 기획: [스킬 수치 초기안](../기획서/유닛스킬.md#스킬-수치-초기안), [지속 효과와 중첩 초기안](../기획서/유닛스킬.md#지속-효과와-중첩-초기안).
- 마법사의 광역 직접 피해·3초 화상과 대마도사의 5초 얼음구역·초당 피해·30% 둔화를 구현한다.
- 같은 화상과 겹친 얼음구역은 각각 하나분의 효과만 적용하고 서로 다른 종류의 피해는 함께 적용한다.
- 이동 라인 ON은 유닛 폭발·화상·얼음 피해/둔화를 같은 라인에 제한한다. 독립 포탑은 물리 범위로 피해를 받고 CC는 무시한다. 상자 실제 HP 감소 SP 귀속도 연결한다.
- 검증: 화상 3회·얼음구역 5회 판정, 구역 진입·이탈·만료, 재적용 시 피해 누락·과다 중첩 방지, 중립 보스 둔화와 은신 중 피해를 확인한다.
- [x] 개발 완료

## 저주술사 기절과 기사단장 버프

- 기획: [스킬 수치 초기안](../기획서/유닛스킬.md#스킬-수치-초기안), [지속 효과와 중첩 초기안](../기획서/유닛스킬.md#지속-효과와-중첩-초기안).
- 저주술사는 사거리 안 가장 가까운 공격 가능한 적을 2초 기절시키고 별도 피해는 주지 않는다.
- 기사단장은 적 유무와 관계없이 발동해 자신을 포함한 당시 모든 아군 플레이어 유닛에 5초간 공격속도 +50%를 적용한다.
- 라인 ON은 같은 라인의 플레이어 소환 유닛만 버프를 받으며 성채 미니언·구조물은 제외한다. 저주술사 기절도 다른 라인과 CC 면역 구조물을 제외한다.
- 기절·경직·동일 버프·동일 둔화는 기획서의 강도·만료 시점 규칙을 따르고 중립 보스에 별도 면역을 부여하지 않는다.
- 검증: 보스 기절, 버프의 양 진영 구분, 자신의 버프, 이후 소환 유닛 제외, 공격 주기 / 1.5, 버프 중첩·만료를 확인한다.
