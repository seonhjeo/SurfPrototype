## 세로형 모바일 화면

- 기획: [게임 방향](../기획서/게임개요.md#게임-방향).
- 모바일 세로 화면에 맞춰 게임 표시와 터치 조작 영역을 구성한다.
- 9:16 세로형을 기준으로 PC·가로 화면에서는 중앙 배치한다(2026-09-30 확정).
- 검증: 합의한 모바일 화면 크기에서 게임 영역과 조작부가 잘리지 않고 터치 좌표가 일치하는지 확인한다.

## 프로토타입 유닛 표현

- 기획: [프로토타입 시각 표현](../기획서/게임개요.md#프로토타입-시각-표현).
- 일반 중립 몬스터는 작은 원, 양 진영의 플레이어 유닛과 중립 보스는 큰 원 + 상징 아이콘으로 표시한다.
- 플레이어 유닛과 보스에 원 반지름 14px·고유 아이콘 16px·금색 테두리 2px·항상 보이는 체력바 폭 28px를 공통 적용한다. 아군·적군 진영색과 보스 내부색을 유지한다(2026-09-30 확정).
- 렌더링 크기만 통일하고 전투 판정 반경과 일반 중립 몬스터 표시는 유지한다.
- 아트 리소스 제작을 최소화한다.
- 켜진 라인·성채 일반/엘리트 미니언·포탑·공용 상자와 구조물 HP를 표시한다. 새 기능 OFF에서는 기존 표시를 유지하며 별도 아트는 만들지 않는다.
- 검증: 아군·적군·보스의 공통 표시 규격, 고유 아이콘과 내부색, 체력이 가득 찬 개체의 체력바, 일반 중립 표시 및 전투 판정 반경 불변을 확인한다.
- [x] 개발 완료

## 1대1 PVP와 AI 경기 기반

- 기획: [게임 방향과 기본 흐름](../기획서/게임개요.md#게임-방향).
- 로비에서 선택한 모드로 비공개 1대1 또는 AI 1대1의 대기방에 진입하고 덱 빌딩과 플레이로 이어지는 경기 흐름을 구성한다.
- [플레이어 유닛 10종](../기획서/플레이어유닛.md)을 고정 제공하며 유닛 수집 기능은 프로토타입 범위에서 제외한다.
- 기본·자동획득 금지·처치획득 금지 모드의 AI 및 서로 다른 기기의 비공개 PVP를 구현한다. [모드 설정](게임모드.md)과 방·코드·준비를 연결하고 [화면 구성 개발단위](화면구성.md)를 따른다. 서버가 전투를 계산하고 WebSocket으로 양쪽에 공통 상태를 전달한다.
- 같은 최종 모드 rules를 사람·AI에 적용하고 비공개 방 생성 시 서버가 rules를 스냅샷으로 고정한다. 참가와 재대전에서도 방의 설정을 유지하고 클라이언트 임의 재정의는 받지 않는다. 세 기본 모드의 새 기능 OFF를 유지한다.
- 검증: 기존 WebSocket 유지 및 최초 연결 대기·PVP 화면 보간 반영 후 Node.js 24의 자동 테스트 59개·타입 검사·프로덕션 빌드를 통과했다. Render 서버와 Vercel 화면의 `main`·`5df7f3a` 공개 배포 후 세 모드의 방 생성·참가·덱 비공개·전투·소환·이탈을 검증했다. 공개 브라우저 두 탭에서 성채 파괴 결과·같은 방 코드의 재대전·참가자 이탈 후 방장 승리를 확인했다. 서로 다른 기기·네트워크는 아직 검증하지 않았으며 배포와 확인 범위는 [공개 PVP 개발단위](공개PVP배포.md)에 기록한다.
- [x] 개발 완료
