# 게임 개요 개발단위

대응 기획: [게임 개요](../기획서/게임개요.md). 기획서의 `확인 필요` 항목은 해당 구현 전에 확정한다.

## 세로형 모바일 화면

- 기획: [게임 방향](../기획서/게임개요.md#게임-방향).
- 모바일 세로 화면에 맞춰 게임 표시와 터치 조작 영역을 구성한다.
- 9:16 세로형을 기준으로 PC·가로 화면에서는 중앙 배치한다(2026-09-30 확정).
- 검증: 합의한 모바일 화면 크기에서 게임 영역과 조작부가 잘리지 않고 터치 좌표가 일치하는지 확인한다.
- [x] 개발 완료

## 프로토타입 유닛 표현

- 기획: [프로토타입 시각 표현](../기획서/게임개요.md#프로토타입-시각-표현).
- 일반 중립 몬스터는 작은 원, 양 진영의 플레이어 유닛과 중립 보스는 큰 원 + 상징 아이콘으로 표시한다.
- 플레이어 유닛과 보스에 원 반지름 14px·고유 아이콘 16px·금색 테두리 2px·항상 보이는 체력바 폭 28px를 공통 적용한다. 아군·적군 진영색과 보스 내부색을 유지한다(2026-09-30 확정).
- 렌더링 크기만 통일하고 전투 판정 반경과 일반 중립 몬스터 표시는 유지한다.
- 아트 리소스 제작을 최소화한다.
- 검증: 아군·적군·보스의 공통 표시 규격, 고유 아이콘과 내부색, 체력이 가득 찬 개체의 체력바, 일반 중립 표시 및 전투 판정 반경 불변을 확인한다.
- [x] 개발 완료

## 1대1 PVP와 AI 경기 기반

- 기획: [게임 방향과 기본 흐름](../기획서/게임개요.md#게임-방향).
- 로비에서 선택한 모드로 비공개 1대1 또는 AI 1대1의 대기방에 진입하고 덱 빌딩과 플레이로 이어지는 경기 흐름을 구성한다.
- [플레이어 유닛 10종](../기획서/플레이어유닛.md)을 고정 제공하며 유닛 수집 기능은 프로토타입 범위에서 제외한다.
- 기본 성채 공방전과 한정 SP 모드의 AI 및 서로 다른 기기의 비공개 PVP를 구현한다. [모드 설정](게임모드.md)과 방·코드·준비를 연결하고 [화면 구성 개발단위](화면구성.md)를 따른다. 서버가 전투를 계산하고 WebSocket으로 양쪽에 공통 상태를 전달한다.
- 검증: 두 모드에서 두 플레이어가 같은 경기 모드·단계 및 결과를 일관되게 확인하는지 검증한다.
- [x] 개발 완료
