# 맵·날씨와 중립 몬스터 개발단위

대응 기획: [맵·날씨와 중립 몬스터](../기획서/맵과중립몬스터.md). 기획서의 `확인 필요` 항목은 해당 구현 전에 확정한다.

## 맵·날씨 선택과 환경 구성

- 기획: [맵과 날씨](../기획서/맵과중립몬스터.md#맵과-날씨).
- 매칭 완료 시 공개할 맵·날씨 종류를 임의로 선택하고 실제 전투 환경에 연결한다.
- 맵·날씨의 종류와 효과는 추후 제공받으며, 가능한 조합 및 경기 중 날씨 변화 여부는 사용자 답변 후 적용한다.
- 검증: 유효한 환경 조합이 선택되고 덱 선택 시 공개한 환경과 일치하는지 확인한다.

## 소환 영역과 중립 몬스터 등장 위치

- 기획: [맵과 날씨](../기획서/맵과중립몬스터.md#맵과-날씨), [등장과 이동](../기획서/맵과중립몬스터.md#중립-몬스터-등장과-이동).
- 맵 아래쪽 절반의 아군 소환 영역, 아군 성채 앞 기본 소환 위치, 맵 중앙 좌·우 등장 위치를 구성한다.
- 지형·장애물·이동 경로·소환 불가 위치는 사용자 답변 후 적용한다.
- 검증: 소환 영역 경계와 지정한 등장 위치가 맵 구성에 맞는지 확인한다.

## 중립 몬스터 무리 생성과 이동

- 기획: [중립 몬스터 등장과 이동](../기획서/맵과중립몬스터.md#중립-몬스터-등장과-이동).
- 플레이 시작 5초 후 처음 생성하고, 이후 20초마다 중앙 좌·우에서 맵에 따른 중립 몬스터 무리를 생성한다.
- 중앙 좌·우 각각에서 위·아래 양 진영에 같은 수와 종류가 나뉘어 이동하게 한다.
- 중립 몬스터는 아군·적군 모두를 공격하며, 상세 전투 규칙과 성채 공격 여부는 구현 전에 확정한다.
- 개체 수·구성, 맵별 목록과 능력치는 추후 제공받는다.
- 처치 보상은 [SP 개발단위](SP.md)와 연결한다.
- 검증: 5초·25초·45초의 등장, 양 진영의 동일 구성과 이동, 양 진영 공격 및 경기 종료 후 생성 중단을 확인한다.

## 중립 보스 웨이브

- 기획: [중립 보스](../기획서/맵과중립몬스터.md#중립-보스).
- 중립 몬스터 웨이브 중간중간 보스급 개체를 등장시키고 큰 원 + 상징 아이콘으로 표시한다.
- 보스는 중립 몬스터로 분류하며 등장 웨이브·주기·개체 수와 전투 규칙은 구현 전에 확정한다.
- 검증: 지정한 웨이브에 보스가 등장하고 일반 중립 몬스터와 시각적으로 구분되는지 확인한다.
