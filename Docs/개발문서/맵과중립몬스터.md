# 맵과 중립 몬스터 개발단위

대응 기획: [맵과 중립 몬스터](../기획서/맵과중립몬스터.md). 기획서의 `확인 필요` 항목은 해당 구현 전에 확정한다.

## 맵 선택과 환경 구성

- 기획: [맵과 날씨](../기획서/맵과중립몬스터.md#맵과-날씨), [맵별 기믹](../기획서/맵과중립몬스터.md#맵별-기믹--2026-09-30-확정).
- 사막·숲·늪·성 도로를 제공하고 팝업의 무작위/고정 맵 선택을 실제 환경에 연결한다. 기본은 무작위이며 재대전은 고정 맵 유지·무작위 맵만 재추첨한다.
- 12×20 U 연속 좌표의 일반 전장으로 구성한다. 격자·칸·타일 기반 이동과 소환 스냅은 없다(2026-09-30 확정).
- 환경 선택 확률과 날씨 효과는 [날씨 개발단위](날씨.md)에서 관리한다. 맵별 몬스터 초기안의 명칭과 수치를 연결한다.
- 검증: 맵 네 종류의 고정 선택·무작위, 날씨와 독립 조합, AI/PVP의 공개 환경 일치, 재대전 고정 유지/무작위 재추첨과 무효 환경 거부를 확인한다.
- [x] 개발 완료

## 소환 영역과 중립 몬스터 등장 위치

- 기획: [맵과 날씨](../기획서/맵과중립몬스터.md#맵과-날씨), [등장과 이동](../기획서/맵과중립몬스터.md#중립-몬스터-등장과-이동).
- 맵 아래쪽 절반의 아군 소환 영역, 아군 성채 앞 기본 소환 위치, 맵 중앙 좌·우 등장 위치를 구성한다.
- 라인 0은 장애물·수풀·고정 경로 없는 기존 전장을 사용한다. 1~3라인은 [라인 개발단위](라인.md)의 경로·진입을 연결한다. 자신의 절반 밖·성채·살아 있는 포탑/상자와 겹친 소환은 취소하고 유닛끼리 겹침은 허용한다. 양쪽 모두 자신의 성채가 아래에 보이도록 표시 좌표를 변환한다.
- 검증: 소환 영역 경계와 지정한 등장 위치가 맵 구성에 맞는지 확인한다.
- [x] 개발 완료

## 중립 몬스터 무리 생성과 이동

- 기획: [중립 몬스터 등장과 이동](../기획서/맵과중립몬스터.md#중립-몬스터-등장과-이동), [맵별 기믹](../기획서/맵과중립몬스터.md#맵별-기믹--2026-09-30-확정).
- 플레이 시작 5초 후 처음 생성하고, 이후 20초마다 중앙 좌·우에서 맵에 따른 중립 몬스터 무리를 생성한다.
- `neutralWaves.enabled` 기본 true, count 기본null로 맵별 웨이브를 유지한다. 팝업에서 생성 ON/OFF와 맵 기본 또는 지점·진영당1~10을 설정한다.
- 중앙 좌·우 각각에서 위·아래 양 진영에 같은 수와 종류가 나뉘어 이동하게 한다.
- 중립은 양 플레이어 유닛과 성채를 공격하고 중립끼리는 공격하지 않는다. 공통 120도 부채꼴 탐색·최근접 선택·대상 추적을 적용하며 대상이 없으면 생성 때 배정된 진영의 성채로 이동한다.
- 켠 성채 미니언·포탑을 전투 대상으로 추가한다. 중립은 상자를 공격하지 않으며 이동 라인 진입 전 전투하지 않는다. 진입 뒤 유닛은 같은 이동 라인, 독립 포탑은 물리 거리에 따라 공격한다.
- 기존 명칭·기준 스탯을 사용한다. 맵 기본 수량은 중앙 좌·우 각각 진영당 사막2·숲5·늪/성 도로3이며 직접 수량은 이를1~10으로 대체한다. 각 웨이브 일반 총수는 설정 수×4다.
- 늪 일반 몬스터의 기준 이동속도에 1.3배를 한 번 적용해 실제 이동속도를 1.105 U/초로 계산한다. 상태이상 둔화는 맵 보정 후 속도에 곱하고, 날씨와 웨이브는 중립 이동속도를 바꾸지 않는다.
- 처치 보상은 [SP 개발단위](SP.md)의 중립 enabled/amount를 사용한다. ON은 마지막 타격 진영에 기본 또는 고정 SP를 지급하고 OFF는 일반/보스 모두 지급하지 않는다.
- 검증: 5·25·45초 등장, 맵 기본 및 직접1/10 수량의 지점·진영·전체 수, 중립OFF·늪 속도/둔화, 양진영 이동·공격·보상ON/OFF/고정값, 경기 종료 후 생성 중단을 확인한다.
- [x] 개발 완료

## 웨이브별 체력·공격력 강화

- 기획: [웨이브 강화](../기획서/맵과중립몬스터.md#웨이브-강화).
- 첫 웨이브는 기준값을 사용하고 n번째 신규 생성 개체의 체력·공격력을 `기준값 × 1.07^(n-1)`로 계산한다.
- 일반 몬스터와 보스에 동일한 웨이브 배율을 적용하고, 기존 생존 개체와 이동속도·공격 주기·개체 수·보상은 변경하지 않는다.
- 검증: 1·5·10·15번째 배율, 소수 정밀도 유지, 기존 생존 개체 불변, 첫 웨이브 1~2회 처치 및 후반 수치를 확인한다.
- [x] 개발 완료

## 중립 보스 웨이브

- 기획: [중립 보스](../기획서/맵과중립몬스터.md#중립-보스).
- 5·10·15번째 일반 웨이브에 진영당 보스 1마리·전체 2마리를 추가하고 큰 원 + 상징 아이콘으로 표시한다.
- [보스 초기안](../기획서/맵과중립몬스터.md#맵별-보스-초기안)의 맵별 기준값에 생성 웨이브 배율을 적용한다.
- 늪 보스의 기준 이동속도에 1.3배를 한 번 적용해 실제 이동속도를 1.04 U/초로 계산한다. 맵별 일반 수 변경은 보스 수를 바꾸지 않는다.
- 진영별 중앙 좌·우 50% 독립 추첨 초기안으로 위치를 결정하고, 실제 등장 3초 전에 같은 위치를 경고한다.
- 보스는 날씨 효과에서 제외하고 유닛 스킬의 상태이상과 사냥꾼의 2배 피해는 적용한다.
- 보스 고유 스킬은 없으며 일반 중립과 같은 이동·탐색 및 단일 기본 공격을 적용한다(2026-09-30 확정).
- 중립 웨이브OFF는 보스 경고/생성도 끈다. 일반 수량을1~10으로 바꿔도 보스는 진영당1개와 기존 경고/주기를 유지한다. 라인ON은 일반과 같은 진입·전투 규칙을 적용한다.
- 검증: 82·182·282초 경고와 85·185·285초 등장, 경고·실제 위치 일치, 맵별 일반 수 유지, 진영당 보스 1마리, 늪 보스 속도 및 조기 경기 종료 시 경고·생성 중단을 확인한다.
- [x] 개발 완료
