# 초기 밸런스 검증 개발단위

대응 기획: [초기 밸런스 기준](../기획서/밸런스기준.md). 계산으로 확인한 수치와 실제 대전으로 확인한 결과를 구분한다.

## 수치 관리와 계산 일관성

- 기획: [수치의 성격](../기획서/밸런스기준.md#수치의-성격), [단위와 계산 초기안](../기획서/밸런스기준.md#단위와-계산-초기안).
- 사용자 지정값과 조정 가능한 초기안을 구분하고, 공통 거리 단위 U와 소수 정밀도를 사용한다.
- 기획 표·게임 데이터·날씨 및 상태이상 보정에서 같은 값을 사용한다.
- 검증: 7% 복리 계산, 표시 반올림과 실제 피해·승패 판정 분리, 공격속도와 공격 주기 환산, 사람·AI의 동일 수치를 확인한다.

## AI 상대 대전과 후반 압박 검증

- 기획: [실제 대전에서 확인할 항목](../기획서/밸런스기준.md#실제-대전에서-확인할-항목).
- 각 맵·날씨에서 사람 대 AI 1대1을 시작부터 종료까지 검증한다.
- 첫 웨이브 일반 몬스터의 1~2회 처치, 후반 웨이브의 성채 압박, 보스 대응과 권장 3분 경기 길이를 확인한다.
- 사냥꾼 반복 소환, 원거리 집결, 기사단장·대마도사 중첩 전략을 확인하고 초기안 수치를 조정한다.
- 검증: 실제 실행한 경기 조건과 결과를 기록하고 기획·개발문서를 함께 갱신한다. 산술 계산만으로 이 단위를 완료 처리하지 않는다.
