# 유닛과 전투 개발단위

대응 기획: [플레이어 유닛과 자동 전투](../기획서/유닛과전투.md). 기획서의 `확인 필요` 항목은 해당 구현 전에 확정한다.

## 터치·드래그 소환

- 기획: [소환 조작](../기획서/유닛과전투.md#소환-조작).
- 단순 터치 시 아군 성채 앞, 터치 후 드래그 시 맵 아래쪽 절반의 선택 위치에 소환한다.
- 라인 ON은 [라인 개발단위](라인.md)로 최소 아군 수 탭 배정(미니언 포함)·최근접 드래그 진입을 연결한다. 포탑/상자와 겹친 소환은 취소하고 비용을 소비하지 않는다.
- 소환은 [SP 소비](SP.md)와 연결한다.
- 덱의 유닛은 소모하지 않으며 SP만 충분하면 같은 유닛을 반복 소환한다.
- 아군 영역 밖·성채와 겹친 드롭은 취소하고 유닛끼리 겹침은 허용한다. 연속 좌표 소환 성공 시에만 SP를 차감하고 부족 시 불가 상태를 표시한다(2026-09-30 확정).
- 검증: 터치·드래그 구분, 소환 위치와 비용 처리, 같은 유닛의 반복 소환을 확인한다.

## 전진·전방 감지·대상 추적

- 기획: [이동과 적 탐색](../기획서/유닛과전투.md#이동과-적-탐색).
- 소환 후 적 성채를 향해 전진하고, 전방 120도 부채꼴 범위에서 중립 몬스터와 적 유닛을 감지한다.
- 대상이 감지되면 공격하기 위해 이동한다.
- 여러 대상이 감지되면 가장 가까운 대상을 우선 공격한다.
- 감지 거리는 [유닛 목록](../기획서/플레이어유닛.md)과 [날씨](날씨.md)를 따른다. 이동 방향 기준 120도 부채꼴로 계산하며 격자·사각형 범위가 아니다.
- 동일 거리 후보는 생성 순서로 선택한다. 기존 대상은 감지 거리 이탈·가까운 후보 출현에도 유지하며 사망·은신 시에만 해제한다(2026-09-30 확정).
- 라인 ON은 같은 라인·진입 완료 대상만 탐색/추적한다. 성채 미니언·포탑과 플레이어 소환 유닛 전용 공용 SP 상자를 새 대상에 추가한다.
- 검증: 전방 각도 안팎·거리 안팎의 감지와 여러 대상 중 가장 가까운 대상 선택을 확인한다.

## 사거리 기반 공격과 재탐색

- 기획: [이동과 적 탐색](../기획서/유닛과전투.md#이동과-적-탐색).
- 적 유닛 또는 중립 몬스터가 공격 사거리에 들어오면 이동을 멈추고 공격한다.
- 대상이 살아 있고 숨지 않은 채 공격 사거리를 벗어나면 계속 추격한다.
- 대상이 은신하거나 죽으면 다시 전진하며 적을 탐색한다.
- 도적 은신은 [스킬 개발단위](유닛스킬.md), 기본 공격은 [유닛 목록 개발단위](플레이어유닛.md)를 따른다. 수풀은 없으며 감지 범위 밖 추적을 유지한다.
- 추적 유닛이 없으면 적 성채로 이동해 사거리에서 공격한다. 성채는 기본 공격·스킬·화상 피해를 받고 제어 효과는 무시한다.
- 라인 ON에서 공격·광역·CC는 같은 라인만 적용한다. 포탑은 피해/화상/얼음 허용·CC 무시, 상자는 소환 유닛 피해만 허용한다. 기존 모드 성채 공격 OFF와 새 자동 성채 공격을 독립 처리한다.
- 검증: 사거리 안에서 정지·공격, 사거리 이탈 시 추격, 사망·은신 뒤 재탐색을 확인한다.

## 유닛별 자동 스킬

- 기획: [자동 스킬](../기획서/유닛과전투.md#자동-스킬).
- 유닛별 고유 스킬과 쿨타임을 관리하고 자동으로 사용한다.
- 첫 스킬은 소환 시점부터 쿨타임이 지난 뒤 사용 가능해진다.
- 대상이 필요한 스킬은 쿨타임 완료 시 대상이 없으면 사용 가능 상태로 전진하고, 대상이 사거리에 들어오면 스킬을 우선 사용한다.
- 기사·기사단장은 대상 없이도 준비 즉시 발동한다. 도적은 일반 발동 조건을 따른다.
- 수치·발동·중첩 초기안과 각 스킬 구현은 [스킬 개발단위](유닛스킬.md)와 연결한다.
- 라인 ON에서 모든 스킬 이동·피해·지속 효과·버프를 라인 규칙에 제한한다. 미니언은 중립 보너스 및 플레이어 전용 기사단장 버프에서 제외한다.
- 검증: 첫 쿨타임 대기, 무대상 대기와 기사·기사단장 예외, 스킬 우선 사용 및 기획 표와의 일치를 확인한다.
