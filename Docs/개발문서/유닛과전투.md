# 유닛과 전투 개발단위

대응 기획: [플레이어 유닛과 자동 전투](../기획서/유닛과전투.md). 기획서의 `확인 필요` 항목은 해당 구현 전에 확정한다.

## 터치·드래그 소환

- 기획: [소환 조작](../기획서/유닛과전투.md#소환-조작).
- 단순 터치 시 아군 성채 앞, 터치 후 드래그 시 맵 아래쪽 절반의 선택 위치에 소환한다.
- 소환은 [SP 소비](SP.md)와 연결한다.
- 덱의 유닛은 소모하지 않으며 SP만 충분하면 같은 유닛을 반복 소환한다.
- 영역 밖 드래그·겹침·소환 실패의 처리는 사용자 답변 후 적용한다.
- 검증: 터치·드래그 구분, 소환 위치와 비용 처리, 같은 유닛의 반복 소환을 확인한다.

## 전진·전방 감지·대상 추적

- 기획: [이동과 적 탐색](../기획서/유닛과전투.md#이동과-적-탐색).
- 소환 후 적 성채를 향해 전진하고, 전방 120도 부채꼴 범위에서 중립 몬스터와 적 유닛을 감지한다.
- 대상이 감지되면 공격하기 위해 이동한다.
- 여러 대상이 감지되면 가장 가까운 대상을 우선 공격한다.
- 감지 거리는 [유닛 목록](../기획서/플레이어유닛.md)의 값을 사용하고 [날씨](날씨.md)의 보정을 적용한다. 전방 기준, 같은 거리의 우선순위, 추적 해제·변경 조건은 사용자 답변 후 적용한다.
- 검증: 전방 각도 안팎·거리 안팎의 감지와 여러 대상 중 가장 가까운 대상 선택을 확인한다.

## 사거리 기반 공격과 재탐색

- 기획: [이동과 적 탐색](../기획서/유닛과전투.md#이동과-적-탐색).
- 적 유닛 또는 중립 몬스터가 공격 사거리에 들어오면 이동을 멈추고 공격한다.
- 대상이 살아 있고 숨지 않은 채 공격 사거리를 벗어나면 계속 추격한다.
- 대상이 은신·수풀 기믹으로 숨거나 죽으면 다시 전진하며 적을 탐색한다.
- 도적의 은신은 [스킬 개발단위](유닛스킬.md), 능력치와 기본 공격은 [유닛 목록 개발단위](플레이어유닛.md)를 따른다. 수풀 조건, 감지 범위 이탈 처리와 성채 공격 조건은 사용자 답변 후 적용한다.
- 검증: 사거리 안에서 정지·공격, 사거리 이탈 시 추격, 사망 또는 은신·수풀로 숨은 뒤 재탐색을 확인한다.

## 유닛별 자동 스킬

- 기획: [자동 스킬](../기획서/유닛과전투.md#자동-스킬).
- 유닛별 고유 스킬과 쿨타임을 관리하고 자동으로 사용한다.
- 첫 스킬은 소환 시점부터 쿨타임이 지난 뒤 사용 가능해진다.
- 대상이 필요한 스킬은 쿨타임 완료 시 대상이 없으면 사용 가능 상태로 전진하고, 대상이 사거리에 들어오면 스킬을 우선 사용한다.
- 기사·기사단장은 대상 없이도 준비 즉시 발동한다. 도적은 일반 발동 조건을 따른다.
- 수치·발동·중첩 초기안과 각 스킬 구현은 [스킬 개발단위](유닛스킬.md)와 연결한다.
- 검증: 첫 쿨타임 대기, 무대상 대기와 기사·기사단장 예외, 스킬 우선 사용 및 기획 표와의 일치를 확인한다.
