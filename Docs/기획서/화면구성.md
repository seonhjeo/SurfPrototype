# 프로토타입 화면 구성

## 전체 흐름

- 경기 생성 흐름은 로비 → 경기 설정 팝업 → 준비방 → 게임이다. 코드 참가는 로비 → 준비방 → 게임 순서로 진행한다.
- 로비에서 대전 방식을 선택하고 설정을 완료한다. 준비방에서 환경 확인·덱 선택·준비를 진행한 뒤 게임 화면으로 이동한다.
- 준비방은 기존의 대기방·[덱 빌딩](덱빌딩.md) 단계, 게임은 [플레이](전투진행.md) 단계에 대응한다.

## 로비

- 성채 공방전의 AI 대전·비공개 방 생성·초대 코드 참가를 제공한다. 기존 모드 선택 영역과 두 추가 고정 모드는 삭제한다.

| 선택 항목 | 동작 | 이동 화면 |
| --- | --- | --- |
| AI와 대전 | 설정 팝업에서 경기 규칙을 정한다. | 설정 완료 후 AI 준비방 |
| 비공개 방 만들기 | 설정 팝업 완료 후 방을 만들고 숫자 6자리 코드를 발급한다. | 생성한 방의 준비방 |
| 비공개 방 참가 | 숫자 6자리 코드로 방장 설정을 받는다. | 참가한 방의 준비방 |

- 초대 코드로 참가하면 방장이 정한 경기 설정으로 플레이한다는 점을 안내한다.
- 모든 신규 게임·모드의 AI 상대 1대1 지원 원칙은 [개발 지침](../../AgentDocs/Development.md)을 따른다.

## 경기 설정 팝업 — 2026-10-01 확정

- AI 대전과 비공개 방 만들기를 누르면 준비방 진입보다 먼저 설정 팝업을 연다. 두 경로는 같은 설정 항목을 사용하며 완료 버튼은 선택한 경로를 실행한다.
- [경기 설정 항목](게임모드.md#설정-항목과-수량-범위)을 환경 → 전장과 병력 → 성채와 구조물 → SP 획득 순서로 표시한다. 맵/날씨 선택과 각 기능의 ON/OFF·수량·SP량·단위·허용 범위를 확인할 수 있다.
- 환경에서 맵은 무작위/사막/숲/늪/성 도로, 날씨는 무작위/화창함/비/안개 중 각각 선택한다. 기본은 둘 다 무작위이며 고정/무작위 재대전 정책을 안내한다.
- 포탑 파괴 SP는 SP 획득 섹션 맨 아래에 놓는다. 기본 OFF·ON 초기 입력 5·1~50 정수와 파괴된 포탑 소유진영이 받는다는 도움말을 제공한다.
- 투석기·끓는 기름은 ON/OFF만 제공한다. 이동 라인은 0~3개이며 0은 자유 이동이다. 포탑 항목은 독립적인 배치 라인 1~3개와 라인당 포탑 1~3개를 입력하며 이동 라인 0에서도 설치 가능하다고 안내한다.
- HP·피해·공격 주기·사거리·강화 배율·엘리트 출현 주기 등 전투 스탯 입력은 제공하지 않는다.
- 일반 항목은 OFF 상태에서 숫자 입력을 비활성화하고 입력값을 보존한다. 이동 라인은 OFF와 0개를 동기화하며 숫자를 계속 입력할 수 있다. 같은 팝업 안에서 다시 ON으로 바꾸면 직전 양수 라인 수를 복원한다.
- 초기화는 기본 규칙을 복원한다. 최근 완료한 설정은 앱 세션 안에서 유지하며 새 팝업의 초기값으로 사용한다. 새로고침 등 이후의 영구 저장은 하지 않는다.
- 취소하면 로비에 머물며 경기·방을 만들지 않는다. 완료 전에는 AI 준비 타이머나 방 생성을 시작하지 않으며 취소한 변경은 최근 완료 설정에 반영하지 않는다.
- 허용 범위를 벗어난 수치나 형식 오류는 해당 설정을 안내하고 완료를 막는다. 설정 완료 후 확정값을 AI 경기 또는 비공개 방 생성에 전달한다.
- 모바일 세로 화면에서도 모든 설정과 취소·초기화·완료 버튼에 접근할 수 있게 한다. 키보드로도 팝업의 입력과 버튼을 사용할 수 있게 한다.

## 대기방

- 확정된 경기의 실제 맵과 날씨를 확인하고 덱을 선택한다. 설정 확인 UI는 맵/날씨의 무작위·고정 선택 정책도 표시한다.
- 시작 SP·초당 회복·종류별 처치 및 포탑 파괴 보상과 켜진 기능·수량을 확인할 수 있는 설정 확인 UI를 제공한다. 생성 시 확정된 설정을 보여 주며 여기서 변경하지 않는다.
- 표시 수치는 해당 경기의 최종 rules를 사용한다. 비공개 경기 설정은 서버가 고정한 방장 rules를 참가자와 공유한다.
- 맵 기본 중립 수량은 [맵 기믹](맵과중립몬스터.md#맵별-기믹--2026-09-30-확정)을 공개한다. 수량을 직접 설정했다면 실제 적용한 좌·우 각각 진영당 수량을 표시하며 늪 이동속도 +30%는 유지한다. 중립 OFF이면 생성을 끈 상태를 표시한다.
- 덱은 고정 제공 유닛 10종 중 중복 없이 선택하는 5슬롯이며 상세 규칙은 [덱 빌딩](덱빌딩.md)을 따른다.
- 덱 선택 제한시간은 양쪽 참가자가 모두 입장한 뒤 시작하는 공통 30초다. 방장 혼자 기다리는 동안에는 진행하지 않으며 시작 후 남은 시간을 표시한다.
- 최소 1슬롯 선택 시 준비를 허용하고 상대 준비 상태를 보여 준다. 준비 중 덱 편집을 잠그며 상대가 아직 미준비일 때만 준비를 취소할 수 있다.
- 준비 취소는 선택 제한시간을 초기화하지 않는다. 비공개 방에서는 숫자 6자리 초대 코드를 확인할 수 있다.
- 양측 준비 완료 또는 제한시간 종료 시 기존 선택을 유지하고 빈 슬롯만 중복 없는 랜덤 유닛으로 채운 뒤 게임 화면으로 이동한다.
- AI 대전도 설정 완료 후 플레이어와 AI가 준비방에 참가하며 같은 30초 규칙을 사용한다. AI는 덱 선택을 마치면 자동 준비한다.

## 게임

- 준비방에서 확정한 경기 설정·실제 맵·날씨·덱을 사용한다. 현재 SP·회복·처치 및 포탑 파괴 보상 안내를 실제 규칙과 일치시킨다.
- 현재 맵의 실제 적용 기믹을 표시한다. 켜진 [라인](라인.md)·[미니언](성채미니언.md)·[포탑/SP 상자](구조물.md)와 구조물 체력을 전장에 표시한다.
- 기본 조합에서는 기존 자유 이동 전장과 기본 SP 규칙을 유지한다. 제한시간·승패·SP 소환·자동 전투는 [전투 진행](전투진행.md), [SP](SP.md), [유닛과 전투](유닛과전투.md)를 따른다.

## 방 수명과 오류 처리 — 2026-09-30 확정

- 별도 로그인 없이 두 플레이어가 6자리 코드로 같은 비공개 방에 참가한다. 코드는 방이 열려 있는 동안만 유효하며 닫힌 코드로 재접속할 수 없다.
- 잘못된 코드·만료된 코드·존재하지 않는 방·가득 찬 방은 오류를 안내한다.
- 방장은 설정 팝업을 완료한 뒤 방을 생성한다. 코드 참가자는 팝업을 거치지 않고 방장 설정을 공유한다.
- 준비방에서 참가자가 이탈하면 선택 타이머와 양쪽 준비 상태를 초기화한다. 새 참가자가 들어오면 공통 30초를 다시 시작한다.
- 준비방에서 방장이 이탈하면 방을 종료하고 상대에게 알린다. 경기 중 이탈·연결 종료는 해당 플레이어 패배이며 재접속은 제공하지 않는다.

## 결과와 재대전 — 2026-09-30 확정

- 승리·패배·무승부와 종료 사유를 표시하고 다시 준비·로비 복귀를 제공한다.
- PVP는 양 참가자의 재대전 선택 후, AI는 재대전 선택 후 설정 팝업 없이 같은 설정의 준비방으로 이동한다.
- 비공개 재대전은 같은 방 코드와 서버의 규칙/환경 정책 스냅샷을 유지한다. 양 경로 모두 고정 맵·날씨는 유지하고 무작위 항목만 재추첨한다. 덱·준비·전투·초기 SP·개체·생성 타이머는 새로 시작한다.
