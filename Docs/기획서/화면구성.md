# 프로토타입 화면 구성

## 전체 흐름

- 프로토타입은 로비 → 대기방 → 게임의 세 화면으로 구성한다.
- 로비에서 모드와 대전 방식을 선택하고, 대기방에서 환경 확인·덱 선택·준비를 진행한 뒤 게임 화면으로 이동한다.
- 대기방은 기존의 [덱 빌딩](덱빌딩.md) 단계, 게임은 [플레이](전투진행.md) 단계에 대응한다.

## 로비

- 여러 게임 모드 중 하나를 선택한다.
- 선택한 모드에 대해 다음 세 가지 대전 진입 방식을 제공한다.

| 선택 항목 | 동작 | 이동 화면 |
| --- | --- | --- |
| 1대1 비공개 방 생성 | 선택한 모드의 비공개 방을 만들고 숫자 6자리 초대 코드를 발급한다. | 생성한 방의 대기방 |
| 1대1 비공개 방 참가 | 전달받은 숫자 6자리 초대 코드를 입력해 해당 방에 참가한다. | 참가한 방의 대기방 |
| AI와 대전 | 선택한 모드에서 AI를 상대하는 1대1 대전을 시작한다. | AI 대전의 대기방 |

- 비공개 방의 초대 코드를 다른 플레이어에게 알려 참가할 수 있게 한다.
- 모든 신규 게임·모드의 AI 상대 1대1 지원 원칙은 [개발 지침](../../AgentDocs/Development.md)을 따른다.

## 대기방

- 해당 경기의 맵과 날씨를 확인하고 유닛을 덱 슬롯에 선택한다.
- 현재 기획된 게임의 덱은 고정 제공 유닛 10종 중 중복 없이 선택하는 5슬롯이며, 상세 규칙은 [덱 빌딩](덱빌딩.md)을 따른다.
- 덱 선택 제한시간은 양쪽 참가자가 모두 입장한 뒤 시작하는 공통 30초다. 방장 혼자 상대를 기다리는 동안에는 진행하지 않으며, 시작 후 남은 시간을 화면에 표시한다.
- 최소 1개의 슬롯을 채우면 준비 버튼을 눌러 준비 상태가 될 수 있고, 상대의 준비 상태를 확인할 수 있다.
- 준비 상태에서는 덱을 바꿀 수 없다. 상대가 아직 준비 상태가 아닐 때만 자신의 준비를 취소할 수 있으며, 취소 후에는 다시 덱을 바꿀 수 있다.
- 준비 취소는 시작된 30초 선택 제한시간을 초기화하지 않는다.
- 비공개 방에서는 참가에 사용할 숫자 6자리 초대 코드를 확인할 수 있게 한다.
- 양측이 모두 준비 상태이거나 선택 제한시간이 종료되면 미선택 슬롯을 중복 없는 랜덤 유닛으로 채운 뒤 게임 화면으로 넘어간다.
- 조기 시작과 시간 종료 모두 기존에 선택한 유닛을 유지하고 빈 슬롯만 채워, 각 플레이어의 덱을 5슬롯으로 확정한다.
- AI 대전도 플레이어와 AI가 대기방에 참가한 뒤 같은 30초 규칙으로 맵·날씨 확인과 덱 선택을 거쳐 게임으로 이동한다.
- AI는 덱 선택을 마치면 자동으로 준비 상태가 되며, 플레이어는 AI의 준비 여부를 확인할 수 있다.

## 게임

- 실제 플레이가 진행되는 화면이다.
- 대기방에서 선택한 모드·맵·날씨·확정 덱을 사용한다.
- 현재 기획된 게임의 제한시간·승패, SP 소환과 자동 전투는 [전투 진행](전투진행.md), [SP](SP.md), [유닛과 전투](유닛과전투.md)를 따른다.

## 확인 필요

- 로비에서 제공할 구체적인 모드 목록·이름과 모드별 규칙.
- 초대 코드의 유효기간·재사용 및 잘못된 코드·가득 찬 방 처리 방식.
- 로비에서 선택한 모드와 참가 코드의 방 모드가 다를 때 처리 방식.
- 대기방 이탈·방장 이탈·연결 종료, 경기 종료 후 결과 표시와 복귀 화면.
