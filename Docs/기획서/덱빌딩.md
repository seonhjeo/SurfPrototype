# 덱 빌딩

## 진입과 환경 공개

- 로비에서 비공개 방 생성·참가 또는 AI 대전을 선택해 [대기방](화면구성.md#대기방)에 진입하고 덱 빌딩을 진행한다.
- 임의로 선택된 맵과 날씨 종류를 표시한다.
- 플레이어는 공개된 맵과 날씨를 바탕으로 사용할 유닛을 선택한다.
- 프로토타입에서 제공하는 고정된 유닛 종류 중 선택하며, 유닛 수집 과정은 포함하지 않는다.
- 고정 제공 목록은 전사·궁수·도적·방패병·마법사·기사·저주술사·사냥꾼·기사단장·대마도사의 [10종](플레이어유닛.md)이다.
- 환경의 세부 사항은 [맵과 중립 몬스터](맵과중립몬스터.md)를 따른다.

## 덱 구성

- 덱은 우선 5슬롯으로 구성한다.
- 같은 유닛을 중복 선택할 수 없다.
- 플레이 중 소환해도 선택한 유닛을 소모하지 않으며, SP만 충분하면 같은 유닛을 다시 소환할 수 있다.

## 선택 제한시간

- 양쪽 참가자가 대기방에 모두 입장하면 공통 선택 제한시간 30초를 시작한다. 방장 혼자 대기하는 시간은 포함하지 않는다.
- 제한시간을 넘기면 선택되지 않은 슬롯을 랜덤 유닛으로 채운다.
- 자동 선택은 미선택 슬롯에만 적용하며, 플레이어가 이미 선택한 슬롯은 유지한다.
- 자동 선택에도 동일 유닛 중복 금지 규칙을 적용하여, 이미 선택된 유닛을 제외한 후보로 빈 슬롯을 채운다.
- 30초 선택 제한시간이 종료되면 빈 슬롯을 채워 덱을 확정하고, 준비 여부와 관계없이 게임 화면의 [플레이 단계](전투진행.md)로 이어진다.

## 준비와 조기 시작

- 대기방에 준비 버튼을 제공하고 상대가 준비 상태인지 확인할 수 있게 한다.
- 최소 1개 슬롯을 채우면 준비할 수 있다. 모든 슬롯이 비어 있으면 준비할 수 없다.
- 준비 중에는 덱을 변경할 수 없다. 상대가 아직 준비하지 않았을 때만 준비를 취소할 수 있고, 취소 후 덱 변경이 다시 가능하다.
- 준비 취소는 선택 제한시간을 초기화하지 않는다.
- 양측이 모두 준비 상태이면 30초가 남아 있어도 각자의 빈 슬롯을 중복 없는 랜덤 유닛으로 채우고, 5슬롯 덱을 확정해 즉시 게임 화면으로 이동한다.
- 조기 시작의 자동 채움은 시간 만료와 동일하게 기존 선택을 유지하고 빈 슬롯에만 적용한다.
- AI는 덱 선택을 마치면 자동으로 준비 상태가 된다.

## 확인 필요

- 상대의 덱 선택을 공개하는지 여부. 양쪽의 맵·날씨 공유는 [날씨 선택 초기안](날씨.md#선택-확률-초기안)을 따른다.
