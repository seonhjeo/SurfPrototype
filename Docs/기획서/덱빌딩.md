# 덱 빌딩

## 진입과 환경 공개

- 매칭 완료 후 덱 빌딩 단계에 진입한다.
- 임의로 선택된 맵과 날씨 종류를 표시한다.
- 플레이어는 공개된 맵과 날씨를 바탕으로 사용할 유닛을 선택한다.
- 프로토타입에서 제공하는 고정된 유닛 종류 중 선택하며, 유닛 수집 과정은 포함하지 않는다.
- 환경의 세부 사항은 [맵과 중립 몬스터](맵과중립몬스터.md)를 따른다.

## 덱 구성

- 덱은 우선 5슬롯으로 구성한다.
- 같은 유닛을 중복 선택할 수 없다.
- 플레이 중 소환해도 선택한 유닛을 소모하지 않으며, SP만 충분하면 같은 유닛을 다시 소환할 수 있다.

## 선택 제한시간

- 유닛 선택 가능 시간은 총 30초다.
- 제한시간을 넘기면 선택되지 않은 슬롯을 랜덤 유닛으로 채운다.
- 자동 선택은 미선택 슬롯에만 적용하며, 플레이어가 이미 선택한 슬롯은 유지한다.
- 자동 선택에도 동일 유닛 중복 금지 규칙을 적용하여, 이미 선택된 유닛을 제외한 후보로 빈 슬롯을 채운다.
- 덱 확정 이후 [플레이 단계](전투진행.md)로 이어진다.

## 레디와 조기 시작

- 덱 선택 화면에 레디 버튼을 제공한다.
- 두 플레이어가 모두 레디 버튼을 누르면 30초가 남아 있어도 즉시 플레이를 시작한다.

## 확인 필요

- 고정 제공할 유닛 목록은 추후 제공 예정이다. 중복 없이 5슬롯을 채울 수 있도록 최소 5종이 필요하다.
- 양쪽 플레이어에게 같은 맵·날씨를 공개하는지, 상대의 덱 선택도 공개하는지 여부.
- 레디를 누르기 위한 슬롯 완성 조건, 레디 후 선택 변경·레디 취소 가능 여부.
