# 플레이어 유닛과 자동 전투

## 소환 조작

- 플레이어는 [SP](SP.md)를 사용해 플레이어 유닛을 소환한다.
- 소환할 유닛을 단순 터치하면 아군 성채 앞에서 생성한다.
- 터치 후 드래그하면 아군 영역인 맵 아래쪽 절반 안의 임의 위치에 소환할 수 있다.
- 플레이어 유닛의 시각 표현은 [게임 개요](게임개요.md)의 큰 원 + 상징 아이콘을 따른다.

## 이동과 적 탐색

- 소환된 유닛은 기본적으로 적 성채를 향해 전진한다.
- 유닛 전방의 120도 부채꼴 영역을 감지 범위로 사용한다.
- 감지 범위에 중립 몬스터 또는 적 유닛이 들어오면 해당 대상을 공격하기 위해 이동한다.
- 대상이 유닛의 공격 사거리 안에 들어오면 이동을 멈추고 공격을 시작한다.
- 공격 대상이 숨거나 죽으면 다시 전진하며 적을 탐색한다.
- 감지 범위와 공격 사거리는 별개의 개념이다. 120도는 감지 범위의 각도이며, 감지 거리와 공격 사거리는 별도 설정이 필요하다.

## 자동 스킬

- 각 플레이어 유닛은 고유 스킬을 자동으로 사용한다.
- 스킬 종류와 쿨타임은 유닛마다 다르며, 각 유닛은 자신의 쿨타임인 n초마다 스킬을 사용한다.
- 쿨타임이 완료됐지만 공격할 대상이 없으면 사용 가능한 상태를 유지하며 전진한다.
- 이후 공격 대상이 사거리에 들어오면 스킬을 우선 사용한다.

## 확인 필요

- 덱에서 선택한 유닛의 반복 소환 가능 여부, 소환 후 슬롯의 유지·소모·교체 방식.
- 유닛별 소환 비용, 체력, 이동속도, 감지 거리, 공격 사거리, 공격력, 공격 주기.
- 유닛별 스킬 종류·효과·쿨타임, 소환 직후 최초 스킬 사용 시점 및 쿨타임 시작·재시작 기준.
- 스킬이 기본 공격과 같은 사거리를 사용하는지, 스킬과 기본 공격의 발동이 겹칠 때 처리 방식.
- 전방 방향의 기준, 감지 대상이 여럿일 때 우선순위, 추적 중 목표 변경 조건.
- 대상이 숨는다는 의미가 은신·수풀 등의 기믹인지, 감지 범위를 벗어나는 것인지 여부.
- 살아 있는 공격 대상이 사거리나 감지 범위를 벗어났을 때 추적·재탐색 규칙.
- 성채를 공격 대상으로 인식하는 조건과 성채에 대한 기본 공격·스킬 적용 여부.
- 드래그를 아군 영역 밖에서 끝냈을 때 처리, 유닛·건물·지형과 겹치는 위치의 소환 가능 여부.
- 일반 유닛과 적 보스에도 이 문서의 자동 전투 규칙을 적용하는지 여부.
