# 플레이어 유닛과 자동 전투

## 소환 조작

- 플레이어는 [SP](SP.md)를 사용해 플레이어 유닛을 소환한다.
- 고정 제공 유닛 중 덱에 선택한 5종을 사용하며, SP만 충분하면 같은 유닛을 반복 소환할 수 있다.
- 소환할 유닛을 단순 터치하면 아군 성채 앞에서 생성한다.
- 터치 후 드래그하면 아군 영역인 맵 아래쪽 절반 안의 임의 위치에 소환할 수 있다.
- 플레이어 유닛의 시각 표현은 [게임 개요](게임개요.md)의 큰 원 + 상징 아이콘을 따른다.
- 고정 제공 10종의 비용·능력치·기본 공격은 [플레이어 유닛 목록](플레이어유닛.md)을 따른다.

## 이동과 적 탐색

- 소환된 유닛은 기본적으로 적 성채를 향해 전진한다.
- 유닛 전방의 120도 부채꼴 영역을 감지 범위로 사용한다.
- 감지 범위에 중립 몬스터 또는 적 유닛이 들어오면 해당 대상을 공격하기 위해 이동한다.
- 여러 대상이 감지되면 가장 가까운 대상을 우선 공격한다.
- 대상이 유닛의 공격 사거리 안에 들어오면 이동을 멈추고 공격을 시작한다.
- 공격 대상이 살아 있고 숨지 않은 채 공격 사거리를 벗어나면 계속 추격한다.
- 공격 대상이 숨거나 죽으면 다시 전진하며 적을 탐색한다.
- `숨음`은 은신으로 대상을 찾을 수 없게 되는 상황이며, 단순히 감지 범위를 벗어나는 것과 구분한다. 이번 프로토타입에는 수풀이 없다.
- 감지 범위와 공격 사거리는 별개의 개념이다. 120도는 감지 범위의 각도이며, 감지 거리와 공격 사거리는 별도 설정이 필요하다.

## 자동 스킬

- 각 플레이어 유닛은 고유 스킬을 자동으로 사용한다.
- 스킬 종류와 쿨타임은 유닛마다 다르며, 각 유닛은 자신의 쿨타임인 n초마다 스킬을 사용한다.
- 첫 스킬은 소환 시점부터 해당 유닛의 쿨타임만큼 기다린 뒤 사용 가능해진다.
- 대상이 필요한 스킬은 쿨타임이 완료됐지만 공격할 대상이 없으면 사용 가능한 상태를 유지하며 전진한다. 이후 대상이 사거리에 들어오면 스킬을 우선 사용한다.
- 기사와 기사단장은 예외로, 적이 사거리에 없어도 쿨타임이 완료되면 스킬을 사용한다. 도적은 대상이 필요한 일반 조건을 따른다.
- 스킬별 효과·쿨타임과 은신·상태이상·중첩 초기안은 [유닛 스킬](유닛스킬.md)을 따른다.
- 감지·이동 수치에는 [날씨](날씨.md)의 보정을 적용한다.

## 탐색·추적 확정 규칙 — 2026-09-30 확정

- 탐색은 이동 방향을 중심으로 한 120도 부채꼴의 각도·거리를 연속 좌표로 계산한다. 전방의 격자 칸 수나 사각형 영역이 아니다.
- 동일 거리 후보는 먼저 생성된 유닛을 우선한다.
- 한 번 추적한 대상은 감지 범위를 벗어나거나 더 가까운 다른 대상이 나타나도 계속 추적한다. 사망하거나 은신하면 추적을 해제하고 다시 탐색한다.
- 이번 프로토타입에는 수풀 기믹이 없다. 도적의 은신은 [유닛 스킬](유닛스킬.md)을 따른다.
- 추적할 유닛이 없으면 적 성채를 향해 이동하고, 성채가 공격 사거리에 들어오면 공격한다.
- 성채는 기본 공격·스킬 피해·화상 피해를 받으며 제어 효과는 무시한다. 자체 공격·방어력은 없다.
- 일반 중립 몬스터와 보스도 같은 탐색·추적·공격 규칙을 사용하며, 기본 목표 성채는 생성 시 배정된 진영의 성채다. 중립끼리는 공격하지 않는다.

## 소환 유효성 — 2026-09-30 확정

- 드래그를 아군 영역 밖에서 끝내거나 성채와 겹치는 위치에 놓으면 소환을 취소한다. 경계 위치로 자동 보정해 소환하지 않는다.
- 유닛끼리 겹치는 소환은 허용한다. 격자 스냅은 사용하지 않는다.
- SP는 유효한 소환이 성공했을 때만 차감한다. 취소·실패에는 차감하지 않으므로 환불도 발생하지 않는다.
- SP가 부족하면 소환할 수 없음을 표시하고 소환을 막는다.
