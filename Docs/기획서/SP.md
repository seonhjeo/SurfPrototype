# SP 자원

## 용도와 보유량

- 플레이어는 SP로 [플레이어 유닛](유닛과전투.md)을 소환한다. 유닛별 비용과 기본 처치 보상은 [유닛 목록](플레이어유닛.md)에 정의한다.
- [경기 설정](게임모드.md#설정-항목과-수량-범위)의 시작 SP는 기본 ON·5다. ON이면 1~50 정수, OFF이면 실제 시작 SP는 0이다. OFF에도 입력량은 보존한다.
- 보유 SP 상한은 50으로 고정한다. 회복·처치·포탑 파괴·상자 보상 모두 상한을 적용하며 소수 SP의 계산 정밀도를 유지한다.

## 획득 방식

| 획득 원인 | 기본 설정 | 설정창 조절 |
| --- | --- | --- |
| 시간 경과 회복 | ON·초당 1 SP | ON/OFF·초당 0.1~50 SP, 0.1 단위 |
| 플레이어 소환 유닛 사망 | ON·유닛별 기본 보상 | ON/OFF·기본 보상 또는 공통 1~50 SP 정수 |
| 일반 성채 미니언 사망 | ON·1 SP | ON/OFF·공통 1~50 SP 정수 |
| 엘리트 미니언 사망 | ON·3 SP | ON/OFF·공통 1~50 SP 정수 |
| 중립 일반·보스 처치 | ON·일반 1 SP/보스 8 SP | ON/OFF·기본 보상 또는 공통 1~50 SP 정수 |
| 포탑 파괴 | OFF·ON의 초기 입력 5 SP | ON/OFF·파괴된 포탑 소유진영에 개당 1~50 SP 정수 |
| SP 상자 피해 | 기능 ON 시 실제 감소 HP당 0.1 SP | 상자 ON/OFF와 개수 조절, 피해당 SP는 고정 |

- 웨이브 강화는 중립 처치 보상을 증가시키지 않는다. 기능 생성 ON/OFF와 해당 종류의 처치 보상 ON/OFF는 독립적이다.
- 소환/일반미니언/엘리트/중립 네 종류의 지급은 각각 조절한다. 소환/중립은 개체별 기본 보상과 고정 보상 중 선택하며 일반/엘리트 미니언은 직접 정수량을 입력한다. 중립 고정량은 일반과 보스에 같은 SP를 지급하며 기본 선택은 일반 1·보스 8을 유지한다.
- OFF는 지급하지 않으며 저장된 수량·기본 보상 선택은 보존한다. 자연 회복·처치 보상을 모두 끈 조합도 허용한다.

## 종류별 지급 설정과 신규 보상 초기안

- 시간 보상은 enabled와 amount를 분리하고 처치 보상은 카테고리별 enabled와 amount를 사용한다.
- 처치 `amount: null`은 개체 정의의 기본 reward ×1, 숫자는 해당 카테고리 공통 보상이다. 기본 일반/엘리트 미니언은 1/3 SP다. 배율은 팝업에 노출하지 않는다.
- 성채·포탑·소환 유닛·성채 미니언이 중립을 마지막 타격으로 처치하면 공격원의 소유진영에 중립 설정 보상을 지급한다. 소유진영이 없는 피해원에는 지급하지 않는다.
- [SP 상자](구조물.md#sp-상자--2026-09-30-확정)는 실제 감소한 HP에 고정 0.1 SP를 곱해 소환 유닛 소유자에게 지급한다. 시간·처치 보상 설정과 독립적으로 동작한다.

## 처치 보상 귀속

- 해당 카테고리 보상이 OFF면 마지막 타격이나 사망 원인과 관계없이 지급하지 않는다. ON일 때 아래 귀속 규칙을 적용한다.
- 플레이어 소환 유닛과 성채 일반/엘리트 미니언이 죽으면 소유자의 상대 플레이어에게 해당 종류의 보상을 지급한다. 중립이 마지막 타격을 해도 상대가 받는다.
- 중립 일반·보스는 마지막 타격을 가한 진영 소속 공격원의 소유 플레이어에게 지급한다. 성채·포탑·미니언 보상 귀속도 같다.

## 포탑 파괴 보상 — 2026-10-01 확정

- 설정 팝업의 SP 획득 섹션 마지막에 포탑 파괴 SP를 둔다. 기본 OFF·입력량 5 SP이며 ON이면 개당 1~50 정수를 지급한다. OFF에도 입력량을 보존한다.
- 파괴된 포탑을 소유한 진영의 플레이어가 받는다. 파괴 주체가 상대 소환 유닛·미니언·중립 등 어떤 공격원이든 귀속은 같다.
- 피해를 가할 때마다 지급하지 않고 포탑 1개가 살아 있다가 파괴될 때 한 번만 지급한다. 이미 파괴된 포탑의 추가 피해는 보상을 만들지 않는다.
- 보유량 상한 50을 적용한다. 포탑 생성·다른 처치 보상·SP 상자 피해 보상과 독립적이며 재대전은 새 포탑마다 같은 지급 규칙을 적용한다.

## 소환과 동시 처치 — 2026-09-30 확정

- SP가 비용보다 적으면 소환 불가를 표시하고 막는다. 위치·덱·보유량이 유효해 실제 소환에 성공한 때만 비용을 차감한다. 취소·실패에는 소비하지 않는다.
- 중립 일반·보스에 동시에 마지막 타격이 들어오면 전투 계산에서 먼저 처리되어 처치한 타격에 보상을 귀속한다. 한 개체의 보상은 한 번만 지급한다.
