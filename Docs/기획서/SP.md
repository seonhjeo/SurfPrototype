# SP 자원

## 용도와 보유량

- 플레이어는 SP를 사용해 [플레이어 유닛](유닛과전투.md)을 소환한다.
- 플레이 시작 시 각 플레이어의 SP는 5다.
- 각 플레이어가 보유할 수 있는 SP의 최대치는 50이다.
- SP 회복이나 처치 보상을 받더라도 보유량은 최대치 50을 넘지 않는다.
- 유닛별 소환 비용과 적에게 지급하는 처치 SP는 [플레이어 유닛 목록](플레이어유닛.md)에 정의한다.

## 획득 방식

| 획득 원인 | 획득량 |
| --- | --- |
| 기본 회복 | 초당 1 SP |
| 중립 몬스터 처치 | 처치한 몬스터 종류마다 정해진 SP |
| 적 유닛 처치 | 처치한 유닛 종류마다 정해진 SP |

- 일반 중립 몬스터 처치 보상은 1 SP, 중립 보스는 8 SP로 둔다. 보상은 초기 밸런스안이며, 웨이브 강화로 증가하지 않는다.
- 중립 몬스터 수치의 기준은 [맵과 중립 몬스터](맵과중립몬스터.md), 보상 선정 근거는 [밸런스 기준](밸런스기준.md)을 따른다.

## 처치 보상 귀속

- 플레이어의 소환 유닛이 죽으면 그 유닛을 소유한 플레이어의 상대에게 SP를 지급한다. 마지막 타격 요건을 적용하지 않으며, 중립 몬스터가 마지막 타격을 했더라도 상대 플레이어가 받는다.
- 중립 몬스터·중립 보스는 자신의 소환 유닛이 마지막 타격을 가한 경우에만 SP를 지급한다.

## 소환과 동시 처치 — 2026-09-30 확정

- SP가 소환 비용보다 적으면 소환 불가 상태를 표시하고 소환을 막는다.
- 소환 위치·덱 포함 여부·보유 SP가 유효하여 실제 소환에 성공한 때만 비용을 차감한다. 취소·실패에는 비용을 차감하지 않는다.
- 중립 몬스터·보스에 양쪽의 타격이 동시에 들어오면 전투 계산에서 먼저 처리되어 대상을 처치한 타격에 보상을 귀속한다. 한 개체의 처치 보상은 한 번만 지급한다.
