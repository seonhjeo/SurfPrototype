# SP 자원

## 용도와 보유량

- 플레이어는 SP를 사용해 [플레이어 유닛](유닛과전투.md)을 소환한다.
- 플레이 시작 시 각 플레이어의 SP는 기본 모드에서 5, 자동획득 금지·처치획득 금지 모드에서 20이다. [게임 모드](게임모드.md)의 규칙을 양쪽에 동일하게 적용한다.
- 각 플레이어가 보유할 수 있는 SP의 최대치는 50이다.
- SP 회복이나 처치 보상을 받더라도 보유량은 최대치 50을 넘지 않는다.
- 위 값은 현재 세 모드의 기본값이다. 미래 모드는 [코드 기반 설정](게임모드.md#코드-기반-모드-설정--2026-09-30-확정)으로 시작·최대 SP를 독립 조절한다. 소수 SP도 계산 정밀도를 유지한다.
- 유닛별 소환 비용과 적에게 지급하는 처치 SP는 [플레이어 유닛 목록](플레이어유닛.md)에 정의한다.

## 획득 방식

| 획득 원인 | 기본·자동획득 금지 모드 | 처치획득 금지 모드 |
| --- | --- | --- |
| 기본 회복 | 기본 모드 초당 1 SP, 자동획득 금지 모드 없음 | 초당 1 SP |
| 중립 몬스터·보스 처치 | 처치한 몬스터 종류마다 정해진 SP | 없음 |
| 적 유닛 처치 | 처치한 유닛 종류마다 정해진 SP | 없음 |

- 일반 중립 몬스터 처치 보상은 1 SP, 중립 보스는 8 SP로 둔다. 보상은 초기 밸런스안이며, 웨이브 강화로 증가하지 않는다.
- 중립 몬스터 수치의 기준은 [맵과 중립 몬스터](맵과중립몬스터.md), 보상 선정 근거는 [밸런스 기준](밸런스기준.md)을 따른다.
- 기본·자동획득 금지 모드의 처치 보상은 동일하다. 처치획득 금지 모드는 모든 처치 보상을 지급하지 않으며, SP 최대치·소환 비용은 세 모드에서 동일하다.

## 종류별 지급 설정과 신규 보상 초기안

- 시간 경과 보상은 지급 여부와 초당 수치를 분리한다. 현재 기본·처치획득 금지 모드는 enabled true·초당 1, 자동획득 금지 모드는 enabled false·초당 0이다.
- 플레이어 소환 유닛·일반 성채 미니언·엘리트 미니언·중립 몬스터/보스의 처치 보상은 각각 ON/OFF와 수치를 조절한다. 중립 일반·보스의 기존 종류별 reward는 유지하고 카테고리 multiplier로 함께 조절할 수 있다.
- `amount: null`은 개체의 기존 reward × multiplier, 고정 amount는 카테고리 공통 보상이다. 초기안은 플레이어 소환 유닛·중립 reward ×1, 일반 미니언 1 SP·엘리트 3 SP다.
- 현재 두 처치 보상 모드는 각 종류의 지급을 켜고 처치획득 금지 모드는 모두 끈다. 미니언 기능 OFF이므로 새 종류 보상은 현재 플레이에 영향을 주지 않는다.
- 성채·포탑·소환 유닛·성채 미니언이 중립을 마지막 타격으로 처치하면 그 공격자의 소유진영 플레이어에게 중립 종류의 보상을 지급하는 초기안이다. 중립끼리는 공격하지 않으며 소유진영이 없는 피해원에는 보상을 주지 않는다.
- 성채 미니언이 죽으면 소유자의 상대 플레이어에게 일반/엘리트 설정의 보상을 지급하는 초기안이다. 플레이어 소환 유닛 사망 보상의 기존 귀속 정책과 일치시킨다.
- [SP 상자](구조물.md#sp-상자--2026-09-30-확정)는 실제 HP 감소당 SP를 소환 유닛 소유자에게 지급한다. 처치 보상이나 시간 보상 ON/OFF와 독립이며 모든 획득은 최종 설정의 SP 상한으로 제한한다.

## 처치 보상 귀속

- 아래 귀속 규칙은 현재 처치 보상이 있는 기본·자동획득 금지 모드에 적용한다. 처치획득 금지 모드는 마지막 타격이나 사망 원인과 관계없이 모든 처치 보상이 0이다. 미래 조합은 카테고리별 enabled를 따른다.
- 플레이어의 소환 유닛이 죽으면 그 유닛을 소유한 플레이어의 상대에게 SP를 지급한다. 마지막 타격 요건을 적용하지 않으며, 중립 몬스터가 마지막 타격을 했더라도 상대 플레이어가 받는다.
- 현재 세 모드의 중립 몬스터·중립 보스는 자신의 소환 유닛이 마지막 타격을 가한 경우에만 SP를 지급한다. 새 공격원 기능을 켠 조합은 위 소유진영 지급 초기안을 따른다.

## 소환과 동시 처치 — 2026-09-30 확정

- SP가 소환 비용보다 적으면 소환 불가 상태를 표시하고 소환을 막는다.
- 소환 위치·덱 포함 여부·보유 SP가 유효하여 실제 소환에 성공한 때만 비용을 차감한다. 취소·실패에는 비용을 차감하지 않는다.
- 중립 몬스터·보스에 양쪽의 타격이 동시에 들어오면 전투 계산에서 먼저 처리되어 대상을 처치한 타격에 보상을 귀속한다. 한 개체의 처치 보상은 한 번만 지급한다.
