# SP 자원

## 용도와 보유량

- 플레이어는 SP를 사용해 [플레이어 유닛](유닛과전투.md)을 소환한다.
- 플레이 시작 시 각 플레이어의 SP는 5다.
- 각 플레이어가 보유할 수 있는 SP의 최대치는 50이다.
- SP 회복이나 처치 보상을 받더라도 보유량은 최대치 50을 넘지 않는다.

## 획득 방식

| 획득 원인 | 획득량 |
| --- | --- |
| 기본 회복 | 초당 1 SP |
| 중립 몬스터 처치 | 처치한 몬스터 종류마다 정해진 SP |
| 적 유닛 처치 | 처치한 유닛 종류마다 정해진 SP |

## 처치 보상 귀속

- 플레이어의 소환 유닛이 죽으면 그 유닛을 소유한 플레이어의 상대에게 SP를 지급한다. 마지막 타격 요건을 적용하지 않으며, 중립 몬스터가 마지막 타격을 했더라도 상대 플레이어가 받는다.
- 중립 몬스터·중립 보스는 자신의 소환 유닛이 마지막 타격을 가한 경우에만 SP를 지급한다.

## 확인 필요

- 유닛별 소환 비용과 중립 몬스터·적 유닛별 처치 보상 수치는 추후 제공 예정이다.
- SP가 부족할 때의 조작·표시 방식.
- 중립 몬스터·보스에 양 플레이어의 마지막 타격이 동시에 발생할 때 귀속 판정 방식.
- 소환 취소·실패 시 SP 차감 시점과 환불 처리.
