# 라인

## 모드별 적용 — 2026-09-30 확정

- [모드 설정](게임모드.md)에서 라인 수를 0~3으로 정한다. 현재 제공하는 세 모드의 기본값은 모두 0이며 기존 자유 이동 전투를 유지한다.
- 1~3은 라인 기능을 켠 상태다. 양쪽 성채 앞에서 모든 라인이 합류하며, 연속 좌표 전장 안의 경로를 사용한다. 격자나 소환 위치 스냅을 도입하지 않는다.
- 라인 기능은 코드 설정으로 조합하며 로비에 기능 설정 UI를 추가하지 않는다. 사람·AI와 양 진영은 같은 설정을 사용한다.

## 라인 진입과 배정

- 외곽에서 생성된 중립 몬스터·보스와 드래그 소환 유닛은 생성 위치에서 가장 가까운 라인으로 최단 거리 진입한다.
- 라인 진입 전에는 최단 진입 이동만 수행하고 새 공격·스킬을 사용하지 않는다. 초기안으로 이미 발생한 투사체·제어 효과의 피격 가능성은 유지하며 진입 중 면역을 부여하지 않는다.
- 단순 터치 소환은 아군 성채 앞에서 생성하며 살아 있는 아군 수가 가장 적은 라인에 배정한다. 집계에는 플레이어 소환 유닛과 성채 일반·엘리트 미니언을 포함한다.
- 배정 후에는 해당 라인을 따라 이동하며 다른 라인으로 옮겨 추적하지 않는다. 합류 구간에서도 배정 라인을 유지한다.
- 동일 거리·동일 아군 수는 가장 낮은 라인 ID를 선택하는 초기안이다. 라인 ID는 화면 아래 진영의 권위 좌표 기준 왼쪽부터 0으로 시작한다.

## 경로 좌표 초기안

- 12×20 U 권위 좌표에서 아래 진영 성채 앞부터 위 진영 성채 앞까지 경유점을 `(6,17.6) → (6,16.4) → (라인 X,14) → (라인 X,6) → (6,3.6) → (6,2.4)`로 둔다.
- 1라인의 X는 6, 2라인은 3·9, 3라인은 2.2·6·9.8이다. 각 구간은 직선으로 연결하며 이동 거리는 경로 길이로 계산한다. 상대 화면은 기존 진영별 좌표 변환을 적용한다.

## 이동·전투·스킬 제한

- 일반 이동·대상 추적·기사 돌진·도적 은신 전진·넉백은 배정된 라인 경로를 따른다. 넉백도 라인 진행 좌표를 뒤로 이동시키며 경로 끝을 넘지 않는다.
- 기본 공격·단일 스킬·광역 피해·화상·얼음구역·제어 효과·버프는 같은 라인에 속한 대상에게만 적용한다. 가까운 다른 라인의 대상에게 효과가 닿아도 적용하지 않는다.
- 공격할 대상이 죽거나 은신하면 기존 탐색 규칙으로 돌아가되 같은 라인에서 다시 탐색한다. 상대 성채는 모든 라인의 종착 목표다. 중앙 SP 상자는 [공용 구조물 초기안](구조물.md#sp-상자--2026-09-30-확정)으로 모든 라인에서 공격할 수 있으며 다른 라인 유닛에 피해를 전파하지 않는다.
- 기사단장 버프는 같은 라인의 아군 플레이어 소환 유닛에만 적용한다. 성채 미니언은 포함하지 않는다.
- 사냥꾼의 중립 2배 피해는 일반 중립 몬스터·중립 보스에만 적용하며 성채 미니언에는 적용하지 않는다.

## 라인 0과 별도 기능의 조합 초기안

- 라인 0은 기존의 자유 이동·추적·스킬 범위를 유지한다.
- 라인 0에서 성채 미니언 또는 포탑만 켜면 가상 1개 경로 분량을 사용한다. 미니언은 진영당 일반 3마리와 지정 웨이브의 엘리트 1마리, 포탑은 진영당 1개다.
- 이 조합은 라인 제한을 켜지 않으며 다른 모드 설정과 독립적으로 운용한다.
