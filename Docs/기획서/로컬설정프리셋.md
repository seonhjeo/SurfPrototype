# 로컬 경기 설정 프리셋

## 저장 범위 — 2026-10-01 확정

- [경기 설정](게임모드.md#설정-항목과-수량-범위)을 이름 붙인 프리셋으로 저장하고 불러온다. AI 대전과 비공개 방 생성은 같은 목록을 사용한다.
- 저장소는 현재 브라우저 프로필과 사이트의 `localStorage`다. 새로고침·브라우저 재실행 뒤에도 남으며 개발 주소와 배포 주소는 서로 다른 저장소를 사용한다. 사이트 데이터를 지우면 프리셋도 삭제된다.
- 현재 `MatchSettings` 전체를 저장한다. 맵·날씨의 무작위/고정 정책, ON/OFF, 수량·SP 값, OFF 항목의 값, `맵 기본`·`개체별 기본 보상`의 `null`, 이동 라인과 독립 포탑 배치 수량을 보존한다.
- 실제 추첨된 맵·날씨, 준비·덱·전투 상태, SP 보유량과 생성 개체·타이머는 저장하지 않는다.
- 이름은 앞뒤 공백을 제거하고 1~40자로 제한한다. 빈 이름이나 기존과 같은 이름으로 새로 저장·이름 변경하는 것은 거부하고 안내한다.
- 프리셋은 최대 100개까지 저장한다. 새 저장이나 가져오기 후 합계가 100개를 넘으면 목록을 바꾸지 않고 안내한다.
- 각 항목은 ID·이름·ISO UTC 생성/수정 시각·설정값을 갖는다. 저장 데이터는 전용 키 아래 `version: 1`과 `presets` 배열을 담는 JSON으로 관리한다.

## 저장·관리와 경기 적용

| 작업 | 동작 |
| --- | --- |
| 새로 저장 | 현재 팝업의 유효한 설정을 새 이름으로 저장한다. |
| 불러오기 | 선택한 프리셋을 팝업의 편집본에 반영한다. |
| 덮어쓰기 | 확인 후 현재 유효한 편집본으로 선택한 프리셋의 설정을 갱신한다. |
| 이름 변경 | 선택한 프리셋의 이름을 바꾸고 설정값은 유지한다. |
| 삭제 | 확인 후 선택한 프리셋을 삭제한다. |
| 기본값으로 초기화 | 팝업의 경기 설정을 기본값으로 되돌리고 프리셋 목록은 유지한다. |

- 불러온 값은 복사해서 편집한다. 불러온 뒤 수량을 바꿔도 원본 프리셋은 바뀌지 않으며 명시적으로 덮어써야 저장된다.
- [설정 완료](화면구성.md#경기-설정-팝업--2026-10-01-확정)를 눌렀을 때만 편집본을 경기 설정으로 확정한다. 불러오기·저장 자체는 경기나 방을 만들지 않는다.
- 취소·닫기는 불러오기와 경기 설정 편집을 폐기한다. 새 저장·덮어쓰기·이름 변경·삭제·가져오기는 즉시 저장되며 팝업 취소로 되돌리지 않는다.
- 최근 완료 설정은 앱 세션 안에서만 기억한다. 새 접속 때 저장된 프리셋을 자동으로 적용하지 않으며 사용자가 직접 불러온다.
- 코드 참가자는 방장의 확정 설정을 받는다. 서버에는 프리셋 메타정보 없이 기존 설정값만 전달하고 제한된 설정 검증을 유지한다.
- 재대전은 이전 확정 설정을 유지한다. 고정 환경 유지·무작위 항목 재추첨과 새 전투 초기화는 [기존 규칙](게임모드.md#진입과-경기-설정-유지)을 따른다.

## JSON 가져오기·내보내기 — 2026-10-01 확정

- 선택한 프리셋 하나와 저장된 전체 프리셋 목록을 각각 JSON 파일로 내보낼 수 있다. 두 파일 모두 `{"version":1,"presets":[...]}` 형식을 사용하며 각 항목은 ID·이름·생성/수정 시각·설정값을 포함한다.
- 내보내기는 저장된 프리셋을 대상으로 한다. 팝업에서만 편집한 값을 포함하려면 먼저 새로 저장하거나 덮어쓴다.
- JSON 파일 가져오기는 지원 버전·전체 항목의 형식·이름·설정값을 검증한 뒤 기존 목록에 추가한다. 파일 중 하나라도 잘못되면 아무 항목도 저장하지 않고 오류를 안내한다.
- 가져올 JSON 파일은 최대 1 MiB로 제한한다. 파일 크기나 가져오기 후 합계 100개 제한을 넘으면 파일 전체를 거부하고 기존 프리셋을 유지한다.
- 같은 이름이 있으면 기존 항목을 유지하고 가져온 이름에 ` (2)`, ` (3)`처럼 사용하지 않은 번호를 붙인다. 파일 내부에서 중복된 이름도 같은 규칙을 적용한다. 번호를 포함해 40자를 넘지 않도록 원래 이름을 줄인다.
- 가져온 항목마다 새 ID와 현재 생성/수정 시각을 부여한다. 같은 파일을 반복해서 가져와도 별도 프리셋으로 추가하며 기존 항목을 덮어쓰지 않는다.
- 파일 안의 원본 ID가 중복되어도 각 항목에 새 ID를 부여한다. 이름 충돌과 별개로 처리한다.
- 가져오기는 목록만 추가하고 현재 경기 설정 편집본을 바꾸지 않는다. 추가한 프리셋을 사용하려면 별도로 선택해 불러온다.
- JSON 내보내기 파일로 서로 다른 브라우저·사이트 사이에서 프리셋을 직접 옮길 수 있다.

## 검증과 오류 처리

- 저장·덮어쓰기는 화면 입력 유효성과 공통 `validateMatchSettings`를 검사한다. 불러오기·가져오기도 같은 경기 설정 스키마를 사용하며 임의 전투 스탯은 허용하지 않는다.
- 손상된 JSON, 잘못된 설정과 지원하지 않는 데이터 버전은 적용하지 않고 안내한다. 설정 구조가 바뀌면 명시적인 버전 변환을 추가하며 미지원 형식을 임의로 해석하지 않는다.
- 저장 목록에 잘못된 항목이 있으면 프리셋 조회·관리·내보내기를 차단해 기존 데이터를 자동 복구하거나 덮어쓰지 않는다. 경기 설정을 직접 편집하고 완료하는 기존 흐름은 사용할 수 있다.
- 저장 접근 차단·용량 부족·쓰기 실패를 성공으로 표시하지 않는다. 실패 시 기존 저장 데이터와 현재 경기 설정 편집본을 보존한다.
- 프리셋 이름은 일반 텍스트로 표시한다. 저장·파일 입력으로 가져온 문자열을 HTML로 실행하지 않는다.
- 모바일 세로 화면과 키보드로 선택·관리·파일 가져오기·내보내기 및 팝업 완료/취소에 접근할 수 있게 한다.
