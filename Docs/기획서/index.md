# 기획서 인덱스

온전한 기획 내용을 플레이어, 맵 등 파트별 문서로 관리한다.

사용자가 지정한 규칙을 확정 사항으로 기록하고, 답변이 필요한 규칙과 수치는 각 문서의 `확인 필요`에 구분한다.
`확인 필요` 항목은 구현 규칙으로 임의 확정하지 않는다.
사용자가 위임한 미제공 수치와 이를 운용하는 초안은 `초기안`으로 표시하며, 사용자 지정 규칙과 구분해 플레이 테스트에서 조정한다.

2026-09-30 질의 답변을 각 파트에 반영했다. 초기 범위는 성채 공방전의 AI·실제 비공개 PVP이며, 연속 좌표 전장·120도 부채꼴 탐색·화면·성채·소환·이탈 규칙을 확정했다. 기획 확인 에이전트가 사용자 답변과 확정 규칙 및 대응 개발문서를 대조해 반영 일치를 확인했다.

같은 날 맵별 일반 몬스터 수(사막 2·숲 5, 중앙 좌·우 각각 진영당)와 늪 일반 몬스터·보스 속도 +30%, 성 도로 무효과를 확정했다. 양 진영 플레이어 유닛의 표시 크기·아이콘 크기·테두리·상시 체력바는 중립 보스와 통일하되 고유 아이콘·진영색과 전투 판정 반경을 유지한다.

추가 요청으로 `자동획득 금지 모드`를 확정했다. 기본 성채 공방전의 시작 5 SP·초당 1 SP를 유지하고, 새 모드는 시작 20 SP·자연 회복 없음만 변경한다. 두 모드는 AI·비공개 PVP를 제공하며 방장 선택 모드를 참가자와 공유하고 재대전에도 유지한다.

이어 `처치획득 금지 모드`를 추가했다. 시작 20 SP·초당 1 SP 회복을 사용하고 모든 중립 몬스터·보스·적 유닛의 처치 SP 보상을 제거한다. 기존 두 모드와 나머지 규칙을 유지하며 세 모드 모두 AI·비공개 PVP와 재대전을 지원한다.

후속 요청으로 표시명을 `자동획득 금지 모드`·`처치획득 금지 모드`로 정리했다. 모드 선택은 기본 모드가 첫 줄 전체 폭을 차지하고 다음 줄에 두 금지 모드를 같은 폭으로 나란히 배치한다. 기존 모드 규칙은 유지한다.

같은 날 후속 요청으로 모드 설정을 코드 기반 기능 조합으로 확장했다. 당시 세 모드의 플레이를 그대로 유지하며 라인0·미니언/성채 공격/포탑/SP 상자 기본OFF를 사용한다. 미래 코드 설정은 1~3라인, 미니언 일반/엘리트 생성, 성채 투석기/기름, 라인별 포탑, 실제 HP감소 기반 SP상자, 시작/상한/시간 및 종류별 처치 SP를 독립 조절한다. 사용자 확정과 위임된 초기안을 구분해 [게임 모드](게임모드.md)와 아래 신규 파트에 정리했다.

2026-10-01 사용자 답변으로 두 추가 고정 모드와 로비 모드 선택을 삭제하고 AI 대전·비공개 방 생성 전에 경기 설정 팝업을 제공한다. SP·라인·중립·미니언·투석기·기름·포탑·상자의 ON/OFF 및 수량/SP량을 조절하며 두 무기는 ON/OFF만 제공한다. HP·피해·주기·엘리트 수/주기·최대SP50은 유지한다. 이동 라인 0~3과 독립 포탑 배치 라인 1~3·라인당 포탑 1~3, 대칭 포탑·중앙 균등 상자 배치를 확정하고 세션 내 완료설정 기억·초기화·취소·참가·재대전 규칙을 [게임 모드](게임모드.md)와 대응 파트에 동기화했다. 앞선 세 모드 문단은 당시 변경 이력이다.

2026-10-01 후속 답변으로 환경 선택(맵/날씨 각각 무작위 또는 기존 목록 고정)을 추가했다. 재대전은 고정 항목 유지·무작위 항목만 재추첨한다. 포탑 파괴 보상은 기본 OFF·ON 초기 5·1~50 정수로, 공격자와 무관하게 파괴된 포탑 소유진영에 개당 한 번 지급한다. UI는 환경 → 전장과 병력 → 성채와 구조물 → SP 획득 순서이며 포탑 파괴 SP는 SP 획득 마지막이다. 기획과 대응 개발단위를 동기화했다.

2026-10-01 후속 요청으로 최대 SP 50을 시간 회복의 자동 획득 한도로 변경한다. 처치·소유 포탑 파괴·상자 피해 보상은 50을 넘겨 전액 지급하며, 50 이상일 때 자동 획득만 정지하고 초과 보유량을 유지한다. 소비로 50 미만이 되면 회복을 재개한다. 시작 입력 1~50과 재대전 초기화는 유지하며 AI·비공개 PVP의 계산·전달·화면 안내를 [SP](SP.md)와 대응 파트에 동기화했다.
