# 기획서 인덱스

온전한 기획 내용을 플레이어, 맵 등 파트별 문서로 관리한다.

사용자가 지정한 규칙을 확정 사항으로 기록하고, 답변이 필요한 규칙과 수치는 각 문서의 `확인 필요`에 구분한다.
`확인 필요` 항목은 구현 규칙으로 임의 확정하지 않는다.
사용자가 위임한 미제공 수치와 이를 운용하는 초안은 `초기안`으로 표시하며, 사용자 지정 규칙과 구분해 플레이 테스트에서 조정한다.

2026-09-30 질의 답변을 각 파트에 반영했다. 이번 범위는 성채 공방전 1개 모드의 AI·실제 비공개 PVP이며, 연속 좌표 전장·120도 부채꼴 탐색·화면·성채·소환·이탈 규칙을 확정했다. 기획 확인 에이전트가 사용자 답변과 확정 규칙 및 대응 개발문서를 대조해 반영 일치를 확인했다.
