# 게임 개요

## 게임 방향

- 세로형 모바일 게임이다.
- 클래시 로얄과 비슷한 CCC, RTS, 1대1 PVP 장르를 지향한다.
- 본 개발 전 게임 아이디어와 조작감을 검증하는 프로토타입이며, 아트 리소스 제작을 최소화한다.
- 프로젝트의 현재 실행 기반은 모바일에서 접근할 수 있는 웹게임이다. 기술 구성은 [프로젝트 지침](../../AgentDocs/Project.md)을 따른다.

## 기본 게임 흐름

매칭 완료 후 게임은 다음 두 단계로 나뉜다.

| 단계 | 주요 내용 | 시간 |
| --- | --- | --- |
| 덱 빌딩 | 임의로 선택된 맵과 날씨를 보고 사용할 유닛을 선택한다. | 최대 30초 |
| 플레이 | SP로 유닛을 소환하고, 자동으로 이동·전투하는 유닛으로 상대 성채를 공략한다. | 제한시간 5분, 권장 플레이시간 3분 |

- 상세 규칙은 [덱 빌딩](덱빌딩.md), [전투 진행](전투진행.md), [유닛과 전투](유닛과전투.md), [SP](SP.md)를 따른다.
- 덱 선택에 제공되는 환경과 플레이 중 등장하는 중립 몬스터는 [맵과 중립 몬스터](맵과중립몬스터.md)에서 정의한다.

## 프로토타입 시각 표현

| 대상 | 표현 |
| --- | --- |
| 일반 유닛 | 작은 원 |
| 플레이어 유닛 | 큰 원 + 상징 아이콘 |
| 적 보스 | 큰 원 + 상징 아이콘 |

## 용어

- 승패 목표 건물은 문서 전체에서 `성채`로 표기한다. 사용자 요청의 `성체`, `성`, `성채`는 같은 목표 건물을 가리키는 것으로 정리했다.
- 자원명은 `SP`로 통일한다.
- `플레이어 유닛`은 사용자가 소환한다고 지정한 유닛을 가리킨다. 일반 유닛 및 적 보스와의 구체적인 분류 관계는 확인이 필요하다.

## 확인 필요

- CCC의 정확한 명칭과 이 프로젝트에서 의미하는 게임 요소.
- 일반 유닛과 플레이어 유닛의 구분, 적 보스의 소속·등장 방식·역할.
- 세로 화면의 기준 비율과 가로 화면 접근 시 처리 방식.
