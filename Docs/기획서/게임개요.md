# 게임 개요

## 게임 방향

- 세로형 모바일 게임이다.
- 클래시 로얄과 비슷한 RTS, 1대1 PVP 장르를 지향한다.
- 원안의 CCC는 유닛을 수집하는 콜렉팅 카드 게임을 의미한다. 이번 프로토타입에서는 수집 요소를 제외하고 고정된 유닛 종류만 제공한다.
- 본 개발 전 게임 아이디어와 조작감을 검증하는 프로토타입이며, 아트 리소스 제작을 최소화한다.
- 프로젝트의 현재 실행 기반은 모바일에서 접근할 수 있는 웹게임이다. 기술 구성은 [프로젝트 지침](../../AgentDocs/Project.md)을 따른다.

## 기본 게임 흐름

화면은 로비 → 대기방 → 게임 순서로 이동한다. 로비에서 모드와 비공개 방 생성·참가 또는 AI 대전을 선택한다. 상세 화면 규칙은 [화면 구성](화면구성.md)을 따른다.

경기 준비와 플레이는 다음 두 단계로 나뉜다.

| 단계 | 주요 내용 | 시간 |
| --- | --- | --- |
| 덱 빌딩 — 대기방 | 맵과 날씨를 보고 유닛을 선택하며 양측 준비 상태를 확인한다. | 선택 제한 30초, 양측 준비 시 조기 시작 |
| 플레이 — 게임 | SP로 유닛을 소환하고, 자동으로 이동·전투하는 유닛으로 상대 성채를 공략한다. | 제한시간 5분, 권장 플레이시간 3분 |

- 상세 규칙은 [덱 빌딩](덱빌딩.md), [전투 진행](전투진행.md), [유닛과 전투](유닛과전투.md), [SP](SP.md)를 따른다.
- [게임 모드](게임모드.md)는 기본 모드, 시작 20 SP·자연 회복 없는 자동획득 금지 모드, 시작 20 SP·초당 1 SP 회복·처치 보상 없는 처치획득 금지 모드를 정의한다.
- 덱 선택에 제공되는 환경과 플레이 중 등장하는 중립 몬스터는 [맵과 중립 몬스터](맵과중립몬스터.md)에서 정의한다.
- [날씨](날씨.md), [플레이어 유닛 10종](플레이어유닛.md), [유닛 스킬](유닛스킬.md), [초기 밸런스 기준](밸런스기준.md)에 상세 수치를 정리한다.
- 세 모드의 지금 플레이를 보존하면서 코드 기반 [모드 설정](게임모드.md)으로 리팩터링한다. [라인](라인.md), [성채 미니언](성채미니언.md), [성채 공격·포탑·SP 상자](구조물.md)는 구현하되 기본 OFF·라인 0으로 두고 미래 모드에 조합한다.

## 프로토타입 시각 표현

| 대상 | 표현 |
| --- | --- |
| 일반 중립 몬스터 | 작은 원 |
| 양 진영 플레이어 유닛 | 중립 보스와 동일한 크기의 큰 원 + 각 유닛의 상징 아이콘 |
| 중립 보스 | 큰 원 + 상징 아이콘 |
| 성채 일반·엘리트 미니언 | 진영 소속과 일반/엘리트를 구분하는 원 + 체력 표시 초기안 |
| 포탑·SP 상자 | 구조물 종류·진영 또는 공용 여부와 남은 체력 표시 초기안 |

- 양 진영 플레이어 유닛과 중립 보스의 표시 규격을 원 반지름 14px·아이콘 글자 크기 16px·금색 테두리 두께 2px·체력바 폭 28px로 통일하고 체력바를 항상 표시한다(2026-09-30 확정).
- 각 유닛의 고유 아이콘과 아군·적군의 진영색, 보스의 내부색을 유지한다. 위 px는 게임 렌더링 기준 좌표이며 화면 확대·축소에 함께 비례한다.
- 이번 통일은 화면 표시 규칙이다. 전투 거리·범위·소환 위치 판정에 쓰는 반경 수치는 그대로 유지한다. 일반 중립 몬스터의 작은 원 표시도 유지한다.

## 용어

- 승패 목표 건물은 문서 전체에서 `성채`로 표기한다. 사용자 요청의 `성체`, `성`, `성채`는 같은 목표 건물을 가리키는 것으로 정리했다.
- 자원명은 `SP`로 통일한다.
- `플레이어 유닛`은 각 플레이어가 SP를 사용해 소환하는 유닛이며, 자기 진영에서는 아군, 상대 진영에서는 적 유닛이다.
- 요청의 `일반 유닛`은 일반 중립 몬스터를 뜻한다.
- 요청의 `적 보스`는 5·10·15번째 중립 웨이브에 추가되는 보스급 개체이며, 문서에서는 `중립 보스`로 표기한다.
- `성채 미니언`은 성채에서 자동 생성하는 진영 소속 일반·엘리트 유닛이다. 플레이어 소환 유닛과 중립 몬스터를 구분하며 사냥꾼 중립 배율·기사단장 플레이어 전용 버프를 받지 않는다.

## 화면과 이번 구현 범위 — 2026-09-30 확정

- 기준 화면은 9:16 세로형이다. PC·가로 화면에서는 세로 게임 화면을 중앙에 배치한다.
- 이번 프로토타입은 `기본 모드`·`자동획득 금지 모드`·`처치획득 금지 모드`를 제공하며 세 모드 모두 AI 1대1과 서로 다른 기기에서 참가하는 비공개 PVP를 지원한다.
- 맵은 격자·타일·칸 단위가 아닌 연속 좌표의 일반 전장이다. U는 거리·속도 계산 단위이며 격자를 뜻하지 않는다.
- 미래 기능 조합은 같은 연속 전장에 1~3라인·미니언·구조물·종류별 SP 설정을 적용한다. 로비의 새 모드/기능 설정 UI는 이번 범위에 포함하지 않는다.
- 경기 결과에서 다시 준비하거나 로비로 돌아갈 수 있다. 이탈·재대전 규칙은 [화면 구성](화면구성.md)을 따른다.
