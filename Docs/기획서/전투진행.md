# 전투 진행과 승패

## 플레이 단계

- 대기방에서 [덱 빌딩](덱빌딩.md)을 마치고 [게임 화면](화면구성.md#게임)으로 이동하면 플레이 단계가 진행된다.
- 플레이 단계의 제한시간은 5분이다.
- 권장 플레이시간은 3분이다. 3분은 플레이 경험의 목표이며, 별도의 종료 조건으로 지정되지 않았다.
- 플레이어는 [SP](SP.md)를 사용해 [플레이어 유닛](유닛과전투.md)을 소환한다.
- 소환한 유닛은 자동으로 전진·탐색·공격·스킬 사용을 수행하며, 중립 몬스터와 적 유닛을 처치하고 상대 성채를 공략한다.
- 플레이 중 일정 시간마다 [중립 몬스터 무리](맵과중립몬스터.md)가 등장한다.
- 중립 몬스터도 성채를 공격해 파괴할 수 있다. 성채 초기·최대 체력은 양쪽 모두 1,000인 [초기 밸런스안](밸런스기준.md)으로 둔다.
- 기본 설정은 라인·미니언·성채 무기·구조물 OFF로 기존 전투를 유지한다. 팝업에서 [라인](라인.md), [미니언](성채미니언.md), [성채 무기·포탑·상자](구조물.md)를 조합해도 제한시간·성채 중심 승패 규칙은 유지한다. 포탑 생존은 성채 공격을 막지 않는다.

## 승리 조건

| 판정 시점 | 승리 조건 |
| --- | --- |
| 제한시간 이내 | 상대 성채를 파괴한다. |
| 제한시간 종료 | 자신의 성채에 남은 체력이 상대 성채의 남은 체력보다 많다. |

## 무승부 조건

- 제한시간 종료 시 양쪽 성채의 남은 체력이 같으면 무승부다.
- 양쪽 성채가 동시에 파괴되면 무승부다.

## 성채 기능과 판정 순서 — 2026-09-30 확정

- 기본 성채는 두 무기 OFF·방어력 없는 피해 목표물이다. 설정 팝업에서 투석기·기름을 각각 켜면 해당 자동 공격을 사용하며 HP·방어력·피해 판정은 유지한다.
- 기본 공격과 스킬 피해·화상 피해는 성채에 적용하고 넉백·기절·경직·둔화 등 제어 효과는 무시한다.
- 시간 종료와 성채 파괴가 동시에 발생하면 성채 파괴를 먼저 판정한다. 같은 전투 판정에서 양쪽 성채가 파괴되면 무승부다.
- 경기 중 이탈 또는 연결 종료는 해당 플레이어의 패배다. 재접속은 제공하지 않는다.
- 확정된 결과 이후 전투를 중단하며 결과 화면의 다시 준비·로비 복귀는 [화면 구성](화면구성.md)을 따른다.
- 경기 종료 뒤 미니언·중립 생성·구조물 공격·상자 재생성도 멈춘다. 재대전에서는 같은 모드 설정으로 모든 전투 개체·SP·웨이브·공격 및 재생성 타이머를 초기화한다.
