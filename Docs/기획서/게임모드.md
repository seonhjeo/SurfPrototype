# 게임 모드

## 제공 모드 — 2026-09-30 확정

| 모드 | 플레이 시작 SP | 시간 경과에 따른 SP 회복 | 처치 SP 보상 |
| --- | --- | --- | --- |
| 기본 모드 | 5 SP | 초당 1 SP | 있음 |
| 자동획득 금지 모드 | 20 SP | 없음 | 있음 |
| 처치획득 금지 모드 | 20 SP | 초당 1 SP | 없음 |

- 로비에서 기본 모드·자동획득 금지 모드·처치획득 금지 모드를 선택할 수 있다.
- 모드 선택은 두 줄로 배치한다. 첫 줄의 기본 모드가 전체 폭을 차지하고, 다음 줄은 자동획득 금지 모드와 처치획득 금지 모드를 같은 폭으로 나란히 표시한다.
- 기존 성채 공방전의 모드 선택 표시는 `기본 모드`로 표기한다.
- 세 모드 모두 AI 상대 1대1과 비공개 PVP를 지원한다.
- 자동획득 금지 모드는 기본 모드에서 시작 SP와 초당 SP 회복만 변경한다.
- 처치획득 금지 모드는 기본 모드에서 시작 SP를 5→20으로 변경하고 모든 처치 SP 보상을 제거한다. 일반 중립 몬스터·중립 보스·적 유닛 처치와 중립 몬스터에 의한 플레이어 소환 유닛 사망 모두 SP를 지급하지 않는다. 자연 회복은 기본 모드와 같은 초당 1 SP다.
- 현재 세 모드의 SP 최대치 50, 소환 비용, 덱·전투·맵·날씨·승패 규칙은 공통으로 적용한다. 새 기능은 모두 OFF·라인 0으로 두어 지금의 플레이를 유지한다.
- 자동획득 금지 모드에서도 처치 보상으로 SP를 획득할 수 있다. 상세 보유량·비용·보상은 [SP 자원](SP.md)을 따른다.

## 선택과 경기 유지

- AI 대전과 비공개 방 생성은 로비에서 선택한 모드로 시작한다.
- 비공개 방의 모드는 방장이 방을 만들 때 정한다. 초대 코드로 참가한 플레이어에게 해당 방의 모드를 전달한다.
- 대기방과 게임에서 현재 경기의 모드와 SP 규칙을 확인할 수 있게 한다.
- 재대전은 이전 경기의 모드를 유지하고, 같은 모드의 대기방에서 덱 선택·준비를 다시 진행한다.

## 코드 기반 모드 설정 — 2026-09-30 확정

- 기존 세 모드를 공통 모드 설정 시스템으로 리팩터링한다. 기능의 ON/OFF와 수치를 조합해 미래 모드를 만들 수 있게 하며 현재 로비에 설정 UI나 새 모드를 추가하지 않는다.
- 모드 식별자 `standard`·`limited-sp`·`no-kill-sp`와 현재 표시명·배치·시작 SP·회복·보상 정책을 유지한다. 새 기능의 구현과 실제 기본 활성화를 구분한다.
- 설정은 `src/game/mode-settings.ts`의 `ModeRules`와 `src/game/data.ts`의 모드 정의에서 관리한다. 미래 코드 조합은 기본 설정에 부분 재정의를 병합하며 한 경기의 사람·AI와 양 진영에 같은 최종 설정을 사용한다.

| 설정 | 현재 세 모드 기본값 | 코드 조절 내용 |
| --- | --- | --- |
| `lanes.count` | 0 | 0~3라인 |
| `neutralWaves.enabled` | true | 기존 중립 몬스터·보스 웨이브 생성 여부 |
| `minions.enabled` | false | 일반·엘리트 미니언 생성 여부와 수량·강화 배율 |
| `fortAttacks.catapult/oil.enabled` | 각각 false | 두 성채 공격을 독립적으로 켜고 피해·주기·사거리·범위 조정 |
| `towers.enabled` | false | 포탑 여부와 HP·공격·배치 진행률 |
| `spBox.enabled` | false | 상자 여부와 HP·피해당 SP·재생성 정책 |
| `sp.initial/maximum` | 시작 5/20/20, 상한 50 | 시작·최대 SP |
| `sp.passive` | 초당 1/0/1 | 지급 여부와 초당 SP |
| `sp.summoned/minion/elite/neutral` | 기존 모드 처치 보상 여부 유지 | 종류별 지급 여부·고정 보상 또는 기준 보상 배율 |

- 보상 `amount: null`은 개체 정의의 기존 보상에 `multiplier`를 곱한다. 고정 amount는 해당 종류의 개체 보상을 대체한다. 소환 유닛·중립은 기준값 ×1, 일반 미니언은 1 SP·엘리트는 3 SP의 초기안이다.
- 상세 규칙은 [라인](라인.md), [성채 미니언](성채미니언.md), [성채 공격과 구조물](구조물.md), [SP](SP.md)를 따른다. 수치가 음수·비유한 값이면 설정을 거부하며 라인 수·개체 수·공격 주기 등 유효성을 검사한다.
