# 게임 모드와 경기 설정

## 기본 규칙과 설정 조합 — 2026-10-01 확정

- `자동획득 금지 모드`와 `처치획득 금지 모드`의 고정 프리셋을 삭제한다. 로비의 모드 선택 UI도 제거하며 성채 공방전의 기능들은 유지한다.
- 기본 경기 규칙은 시작 5 SP·자동 획득 한도 50 SP·자동 회복 초당 1 SP·종류별 처치 보상을 사용한다. 시간 회복만 50까지만 지급하고 다른 보상은 한도를 넘겨 지급한다. 중립 웨이브 ON, 라인·성채 미니언·투석기·끓는 기름·포탑·SP 상자는 OFF다.
- AI 대전과 비공개 방 생성 시 [설정 팝업](화면구성.md#경기-설정-팝업--2026-10-01-확정)에서 맵·날씨와 기능 ON/OFF·수량·SP량을 조합한다. HP·피해·사거리·공격 주기·강화 배율 등 전투 스탯은 설정창에 노출하지 않는다.
- 사람·AI와 양 진영은 같은 확정 설정을 사용한다. 기본 조합은 맵·날씨 각각 무작위, 포탑 파괴 SP 보상 OFF이며 기존 덱·전투·승패·소환 비용을 유지한다.

## 설정 항목과 수량 범위

| 항목 | 기본값 | 설정창 조절 |
| --- | --- | --- |
| 맵 | 무작위 | 무작위 또는 사막·숲·늪·성 도로 고정 |
| 날씨 | 무작위 | 무작위 또는 화창함·비·안개 고정 |
| 이동 라인 | OFF·0라인 | ON/OFF·0~3라인 정수, 0 또는 OFF는 자유 이동 |
| 중립 웨이브 | ON·맵 기본 수량 | ON/OFF·맵 기본 또는 좌·우 각 지점·진영당 일반 1~10마리 |
| 성채 미니언 | OFF·일반 3마리 | ON/OFF·각 진영·라인당 일반 1~10마리 |
| 성채 투석기 | OFF | ON/OFF |
| 성채 끓는 기름 | OFF | ON/OFF |
| 포탑 | OFF·배치 1라인·라인당 1개 | ON/OFF·배치 라인 1~3개·각 진영의 배치 라인당 포탑 1~3개 |
| SP 상자 | OFF·1개 | ON/OFF·전장 중앙 공용 1~3개 |
| 시작 SP | ON·5 SP | ON/OFF·1~50 SP 정수, OFF는 실제 시작 0 SP |
| 자동 SP 회복 | ON·초당 1 SP | ON/OFF·초당 0.1~50 SP, 0.1 단위 |
| 소환 유닛 처치 SP | ON·유닛별 기본 보상 | ON/OFF·기본 보상 또는 공통 1~50 SP 정수 |
| 일반 성채 미니언 처치 SP | ON·1 SP | ON/OFF·공통 1~50 SP 정수 |
| 엘리트 미니언 처치 SP | ON·3 SP | ON/OFF·공통 1~50 SP 정수 |
| 중립 일반·보스 처치 SP | ON·개체별 기본 보상 | ON/OFF·기본 보상 또는 공통 1~50 SP 정수 |
| 포탑 파괴 SP | OFF·ON의 초기 입력 5 SP | ON/OFF·파괴된 포탑 1개당 소유진영에 1~50 SP 정수 |

- 설정 UI는 환경 → 전장과 병력 → 성채와 구조물 → SP 획득 순서다. 포탑 파괴 SP는 SP 획득 섹션의 마지막 항목으로 배치한다.
- 맵·날씨는 각각 무작위/고정을 독립 선택한다. 고정 항목은 재대전에도 유지하며 무작위 항목만 경기마다 다시 추첨한다. 재추첨 결과는 이전과 같을 수도 있다.
- 포탑 파괴 SP는 누가 파괴했는지와 무관하게 파괴된 포탑의 소유진영에 1회 지급한다. 중립에 의해 파괴돼도 같으며 상자 피해·유닛/중립 처치 보상과 독립적이다. 시간 회복을 제외한 모든 SP 보상은 자동 획득 한도 50을 넘겨 전액 지급한다.
- 일반 항목은 OFF로 바꿔도 입력한 수량을 보존하며 숫자 입력을 비활성화한다. 이동 라인은 예외로 OFF와 0개를 동기화하고 숫자 입력을 유지한다. 같은 팝업에서 다시 ON으로 바꾸면 직전의 양수 라인 수를 복원하며, 0개로 확정한 뒤 다시 팝업을 열면 ON의 초기 수량은 1개다.
- SP 자동 획득 한도는 50으로 고정한다. 50 이상에서는 시간 회복을 중단하고 초과 보유량을 유지하며 소비로 50 미만이 되면 회복을 재개한다. 중립 보스는 5·10·15번째 웨이브에 진영당 1마리, 엘리트 미니언은 같은 웨이브에 진영·라인당 1마리를 추가한다. 일반 수량 조절은 이 추가 수량을 바꾸지 않는다.
- 중립 수량의 `맵 기본`은 사막 2·숲 5·늪/성 도로 3마리를 좌·우 각각의 지점·진영마다 생성한다. 직접 정한 수량은 이 맵별 일반 수량을 대체하며 늪 이동속도 +30%는 유지한다.
- 포탑의 배치 라인 수는 이동 라인 수와 독립적이다. 이동 라인이 0이어도 배치 1~3라인을 사용할 수 있으며 배치 라인 수와 라인당 수량을 정해 양 진영에 같은 값을 적용한다. 배치 경로를 따라 양 진영에 대칭으로 놓는다.
- 상자는 y=10에서 1개 x=6, 2개 x=4/8, 3개 x=2/6/10으로 균등 배치한다. [구조물](구조물.md)의 체력·피해·수명은 유지한다.

## 진입과 경기 설정 유지

- 로비에서 `AI와 대전` 또는 `비공개 방 만들기`를 누르면 설정 팝업을 먼저 연다. 설정 완료 후 AI 준비방을 시작하거나 비공개 방을 생성한다.
- 팝업을 취소하면 경기·방을 만들지 않는다. 설정 중에는 준비방의 30초 선택 타이머가 시작되지 않는다.
- 초기화는 위 기본값을 복원하고 저장된 [로컬 설정 프리셋](로컬설정프리셋.md)은 유지한다. 최근 완료한 설정 자체는 현재 앱 세션에서 다음 팝업의 초기값으로 기억하며 자동 영구 저장하지 않는다. 취소한 편집은 최근 완료 설정에 반영하지 않는다.
- 이름 붙인 프리셋은 AI 대전과 비공개 방 생성에서 공유하며 브라우저에 저장하고 JSON으로 가져오기·내보내기할 수 있다. 불러오기는 팝업 편집본만 바꾸고 설정 완료 시 경기에 적용한다. 관리 작업은 즉시 저장되며 취소로 되돌리지 않는다. 새 접속 때 자동 적용하지 않는다.
- 코드로 참가할 때는 팝업을 열지 않고 서버가 고정한 방장 설정을 받는다. 준비방에서 해당 경기의 설정을 확인할 수 있다.
- AI 및 비공개 PVP 재대전은 이전의 규칙·환경 선택 정책을 유지한 준비방으로 이동한다. 고정 맵/날씨는 유지하고 무작위 항목만 다시 추첨한다. 전투 상태·SP·생성 개체·타이머는 초기화한다.

## 설정 모델과 검증

- 팝업 입력은 `src/game/match-settings.ts`의 제한된 경기 설정 스키마로 관리하고 검증한 뒤 `ModeRules`로 변환한다. OFF 수량 보존과 실제 기능 비활성화를 구분한다.
- `src/game/mode-settings.ts`는 공통 전투 규칙, `src/game/data.ts`는 기본 규칙·환경·기존 전투 스탯을 관리한다. 팝업은 맵/날씨 선택과 시작·회복·종류별 보상·수량을 변경한다.
- `MatchSettings.environment`는 map/weather 각각 실제 식별자 또는 random을 사용한다. `towerLossReward`는 enabled/amount로 관리하며 `ModeRules.sp.towerLoss`로 변환한다.
- 내부 중립 수 `neutralWaves.count: null`은 맵 기본이다. `towers.count`·`towers.laneCount`·`spBox.count` 기본은 1이며 기능이 OFF면 생성하지 않는다. `towers.laneCount`는 이동 규칙의 `lanes.count`와 별개다.
- 처치 보상 `amount: null`은 개체 정의의 기본 보상 ×1, 숫자는 해당 종류의 개체에 공통 고정 보상을 사용한다. 미니언 기본은 일반 1 SP·엘리트 3 SP다.
- 서버는 제한된 요청을 검증해 전투 규칙은 `room.rules`, 맵/날씨 선택 정책은 `room.environmentSettings`로 고정한다. 실제 경기의 map/weather와 선택 정책을 참가자에게 전달하고 재대전 때 같은 정책으로 환경을 구성한다. 임의 HP·피해·주기 등의 raw rules 재정의는 허용하지 않는다.
- 존재하지 않는 맵/날씨, 잘못된 ON/OFF 형식, 정수가 아닌 개체 수, 범위 밖·음수·비유한 수치와 허용되지 않은 입력은 거부한다. 참가 및 재대전에서도 서버의 설정 스냅샷을 사용한다.
- 상세 규칙은 [라인](라인.md), [성채 미니언](성채미니언.md), [성채 공격과 구조물](구조물.md), [SP](SP.md)를 따른다.
