# 게임 모드와 경기 설정

## 기본 규칙과 설정 조합 — 2026-10-01 확정

- `자동획득 금지 모드`와 `처치획득 금지 모드`의 고정 프리셋을 삭제한다. 로비의 모드 선택 UI도 제거하며 성채 공방전의 기능들은 유지한다.
- 기본 경기 규칙은 이전 `standard`와 같다. 시작 5 SP·상한 50 SP·자동 회복 초당 1 SP·종류별 처치 보상을 사용한다. 중립 웨이브 ON, 라인·성채 미니언·투석기·끓는 기름·포탑·SP 상자는 OFF다.
- AI 대전과 비공개 방 생성 시 [설정 팝업](화면구성.md#경기-설정-팝업--2026-10-01-확정)에서 기능 ON/OFF와 수량·SP량을 조합한다. HP·피해·사거리·공격 주기·강화 배율 등 전투 스탯은 설정창에 노출하지 않는다.
- 사람·AI와 양 진영은 같은 확정 설정을 사용한다. 기본 조합의 덱·전투·맵·날씨·승패·소환 비용은 유지한다.

## 설정 항목과 수량 범위

| 항목 | 기본값 | 설정창 조절 |
| --- | --- | --- |
| 시작 SP | ON·5 SP | ON/OFF·1~50 SP 정수, OFF는 실제 시작 0 SP |
| 자동 SP 회복 | ON·초당 1 SP | ON/OFF·초당 0.1~50 SP, 0.1 단위 |
| 소환 유닛 처치 SP | ON·유닛별 기본 보상 | ON/OFF·기본 보상 또는 공통 1~50 SP 정수 |
| 일반 성채 미니언 처치 SP | ON·1 SP | ON/OFF·공통 1~50 SP 정수 |
| 엘리트 미니언 처치 SP | ON·3 SP | ON/OFF·공통 1~50 SP 정수 |
| 중립 일반·보스 처치 SP | ON·개체별 기본 보상 | ON/OFF·기본 보상 또는 공통 1~50 SP 정수 |
| 이동 라인 | OFF·0라인 | ON/OFF·0~3라인 정수, 0 또는 OFF는 자유 이동 |
| 중립 웨이브 | ON·맵 기본 수량 | ON/OFF·맵 기본 또는 좌·우 각 지점·진영당 일반 1~10마리 |
| 성채 미니언 | OFF·일반 3마리 | ON/OFF·각 진영·라인당 일반 1~10마리 |
| 성채 투석기 | OFF | ON/OFF |
| 성채 끓는 기름 | OFF | ON/OFF |
| 포탑 | OFF·배치 1라인·라인당 1개 | ON/OFF·배치 라인 1~3개·각 진영의 배치 라인당 포탑 1~3개 |
| SP 상자 | OFF·1개 | ON/OFF·전장 중앙 공용 1~3개 |

- OFF로 바꿔도 입력한 수량은 보존하며 해당 숫자 입력만 비활성화한다. 다시 ON으로 바꾸면 보존된 입력값을 사용한다.
- SP 최대치는 50으로 고정한다. 중립 보스는 5·10·15번째 웨이브에 진영당 1마리, 엘리트 미니언은 같은 웨이브에 진영·라인당 1마리를 추가한다. 일반 수량 조절은 이 추가 수량을 바꾸지 않는다.
- 중립 수량의 `맵 기본`은 사막 2·숲 5·늪/성 도로 3마리를 좌·우 각각의 지점·진영마다 생성한다. 직접 정한 수량은 이 맵별 일반 수량을 대체하며 늪 이동속도 +30%는 유지한다.
- 포탑의 배치 라인 수는 이동 라인 수와 독립적이다. 이동 라인이 0이어도 배치 1~3라인을 사용할 수 있으며 배치 라인 수와 라인당 수량을 정해 양 진영에 같은 값을 적용한다. 배치 경로를 따라 양 진영에 대칭으로 놓는다.
- 상자는 y=10에서 1개 x=6, 2개 x=4/8, 3개 x=2/6/10으로 균등 배치한다. [구조물](구조물.md)의 체력·피해·수명은 유지한다.

## 진입과 경기 설정 유지

- 로비에서 `AI와 대전` 또는 `비공개 방 만들기`를 누르면 설정 팝업을 먼저 연다. 설정 완료 후 AI 준비방을 시작하거나 비공개 방을 생성한다.
- 팝업을 취소하면 경기·방을 만들지 않는다. 설정 중에는 준비방의 30초 선택 타이머가 시작되지 않는다.
- 초기화는 위 기본값을 복원한다. 최근 완료한 설정은 현재 앱 세션에서 다음 팝업의 초기값으로 유지하며 영구 저장하지 않는다. 취소한 편집은 최근 완료 설정에 반영하지 않는다.
- 코드로 참가할 때는 팝업을 열지 않고 서버가 고정한 방장 설정을 받는다. 준비방에서 해당 경기의 설정을 확인할 수 있다.
- AI 및 비공개 PVP 재대전은 이전 경기의 설정을 그대로 유지한 준비방으로 이동한다. 전투 상태·SP·생성 개체·타이머는 초기화한다.

## 설정 모델과 검증

- 팝업 입력은 `src/game/match-settings.ts`의 제한된 경기 설정 스키마로 관리하고 검증한 뒤 `ModeRules`로 변환한다. OFF 수량 보존과 실제 기능 비활성화를 구분한다.
- `src/game/mode-settings.ts`는 공통 전투 규칙, `src/game/data.ts`는 기본 규칙과 기존 전투 스탯을 관리한다. 시작·회복·처치 지급·수량만 팝업에서 변경한다.
- 내부 중립 수 `neutralWaves.count: null`은 맵 기본이다. `towers.count`·`towers.laneCount`·`spBox.count` 기본은 1이며 기능이 OFF면 생성하지 않는다. `towers.laneCount`는 이동 규칙의 `lanes.count`와 별개다.
- 처치 보상 `amount: null`은 개체 정의의 기본 보상 ×1, 숫자는 해당 종류의 개체에 공통 고정 보상을 사용한다. 미니언 기본은 일반 1 SP·엘리트 3 SP다.
- 서버는 방 생성 요청의 제한된 설정을 직접 검증하고 기본 규칙과 결합해 `room.rules`로 고정한다. 클라이언트가 보낸 임의의 HP·피해·주기 등 raw rules 재정의는 허용하지 않는다.
- 잘못된 ON/OFF 형식, 정수가 아닌 개체 수, 범위 밖·음수·비유한 수치와 허용되지 않은 입력은 거부한다. 참가 및 재대전에서도 서버의 설정 스냅샷을 사용한다.
- 상세 규칙은 [라인](라인.md), [성채 미니언](성채미니언.md), [성채 공격과 구조물](구조물.md), [SP](SP.md)를 따른다.
